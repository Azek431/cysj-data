# 创游世界资料库 AI 维护规则

## 总原则

1. 不允许删除原始资料、OCR、截图证据、历史报告。
2. 不允许把待验证内容写成确定结论。
3. 不允许随意改 URL 路径、文件名和导航结构。
4. 不允许新增不存在的站内链接。
5. 修改文档后必须保留或补充 frontmatter。
6. 重要结论要尽量关联 OCR、截图、官方教程或证据等级说明。
7. 中文表达要自然、清楚、适合中国用户阅读。
8. 不要写“本文由 AI 生成”“最后更新时间”这类正文脚注。
9. 不要改 docs/.vitepress/theme，除非任务明确要求 UI 优化。
10. 每次修改后要给出修改摘要、风险点和建议检查命令。
11. 不要自动 git push，不要自动发布 Release。
12. 每轮最多修改 3 篇 Markdown，避免大面积失控。

## 推荐文档结构

新增或深度整理教程类文档时，可优先使用：

- 这篇文档适合谁
- 你能学到什么
- 核心概念
- 最小可做版本
- 推荐变量设计
- 推荐广播设计
- 常见错误
- 相关文档
- 待补充内容

## 检查命令

普通修改后运行：

pnpm run docs:frontmatter:check
pnpm run docs:ui:check

新增、移动、删除文档后运行：

pnpm run docs:sidebar

发版前运行：

pnpm run docs:build

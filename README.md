## ✨ 仓库定位

这是一个兼顾 **GitHub 展示** 与 **知识库导航** 的资料仓库，主要用于：

- 长期归档创游世界相关资料
- 为 AI 问答、知识库、RAG 检索提供基础语料
- 作为后续结构化整理、标签分类与内容提取的数据来源
- 为个人与社区的学习、研究、查阅提供统一入口
- 构建从 **截图证据 → OCR 文本 → 专题研究 → 索引导航** 的知识工程链路

---

## 🌟 仓库亮点

> 这不是一个单纯堆文件的资料夹，而是一个持续工程化整理中的知识库。

- **证据可追溯**：尽量让结论能回到截图、OCR 原文或对应专题整理
- **结构可导航**：通过总索引、阅读路线、映射表和专题入口降低查找成本
- **内容可检索**：为全文搜索、AI 检索、RAG 构建和知识问答提供基础
- **维护可持续**：保留原始资料的分类结构和历史整理记录，同时逐步推进结构化、标签化、专题化整理
- **研究可扩展**：允许将零散线索逐步沉淀为更完整的专题分析与知识图谱

## 🎯 整理目标

为了便于后续将资料用于 AI 学习、知识检索或辅助问答，仓库持续朝以下方向优化：

- 尽可能保留原始资料的分类结构，并在原图恢复后继续核验
- 尽可能完成分类归档
- 尽可能统一命名与目录结构
- 尽可能提高全文检索与专题定位效率
- 为 OCR、文本提取、标签整理与结构化处理提供基础
- 让多数结论都能反向回溯到截图、OCR 或专题文档

换句话说，这个仓库关注的不只是“内容多不多”，还关注：

- 信息是否可被找到
- 结论是否有来源支撑
- 文档之间是否能互相链接
- 后续是否便于继续维护和扩写

## 🛠️ 当前整理方法

仓库当前主要采用以下整理链路：

1. 保留原始资料的分类结构、历史 OCR 记录和已归档文本；原图恢复后再继续核验
2. 在原图可用时对截图进行 OCR 与主题编号映射；当前无原图时优先维护既有 OCR 文档与映射表
3. 将高价值证据整理为专题文档
4. 用总索引、标签体系和待验证清单维护全局结构
5. 持续把“研究线索”升级为“有证据支撑的结论”

这意味着：

- 有些文档已经是较成熟的专题内容
- 有些内容仍处于“证据不足但研究价值较高”的阶段
- 仓库会明确区分 **直接证据、归纳结论、社区推测、待验证内容**

## 📝 文档状态与证据等级

为便于后续维护，建议在新增或重构文档时参考以下状态与证据标识：

### 文档状态

- `草稿`：仅完成初步整理，结构和结论仍可能变化
- `整理中`：已开始分类和归纳，但尚未完全补齐来源与索引
- `已结构化`：已有较清晰的层级、主题和交叉链接
- `待验证`：包含推测、观察或证据不足的内容，需后续核对
- `已复核`：已完成主要来源检查与内容核对

### 证据等级

- `E1 直接证据`：可核验原始截图、官方文本、更新说明、明确界面信息
- `E2 OCR/转写证据`：从截图或图像中提取出的文本内容
- `E3 归纳结论`：基于多个证据整理出的稳定结论
- `E4 社区经验/推测`：来源于经验总结、讨论或尚未完全验证的推断

> 建议：若结论主要建立在 `E4` 上，应显式标记“待验证”，避免误导性表达。

## 📛 命名与维护规范

为了让仓库长期可维护、可搜索、可扩展，建议遵循以下规则：

### 命名建议

- 标题尽量直接体现主题，而不是使用过于模糊的名字
- 优先使用统一中文命名，必要时补充版本号、对象名、模块名
- 对 OCR、映射、专题、索引类文档采用稳定命名风格，避免频繁改名
- 同一主题下的文件命名尽量保持并列一致，方便批量检索

### 内容组织建议

- 原始证据与整理结论尽量分层存放，不混写在同一个段落里
- 文档开头可补充：主题、来源、状态、关联索引、最后更新时间
- 文档结尾可补充：相关阅读、引用来源、待补问题、后续行动
- 若新增专题文档，建议同步挂到总索引、标签体系或阅读路线中

### 表达建议

- 区分“看到的现象”“基于现象的推断”“已经确认的结论”
- 不确定的信息尽量写成“可能”“疑似”“待验证”，不要写死
- 多来源结论优先写明依据，减少纯主观表述

## 🤝 贡献建议

如果你希望继续补充这个仓库，建议优先从以下方向入手：

1. **补证据**：为已有结论补齐截图、OCR 原文或来源链接
2. **补索引**：把高价值新文档挂到总索引、阅读路线或标签体系中
3. **补结构**：把零散记录升级为专题文档、对照表或映射表
4. **补标记**：为不确定内容显式加上“待验证”或证据等级说明
5. **补关联**：把相近主题文档互相链接，减少信息孤岛

如果是一次较大的整理更新，建议至少同步检查：

- 总索引是否需要新增入口
- 标签体系是否需要补新分类
- OCR 映射表是否需要补编号
- 待验证问题清单是否需要更新状态
- 路线图或复盘文档是否需要追加记录

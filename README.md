# 创游世界资料汇总

一个面向 AI 检索、知识整理与学习研究的创游世界资料仓库。

本仓库主要收集、归档并持续整理与创游世界相关的各类资料，内容涵盖脚本、组件、编辑器界面、对象结构、引擎更新、教程截图及其他可用于学习、分析、检索和知识构建的信息。仓库的目标不仅是保存资料，也希望尽可能将分散内容整理为更适合 AI 理解、索引和调用的语料集合。

## 仓库定位

本仓库主要用于以下用途：

- 作为创游世界相关资料的长期归档库
- 作为 AI 问答、知识库、RAG 检索的基础语料
- 作为后续结构化整理、标签化分类和内容提取的数据来源
- 作为个人与社区学习、研究、查阅的资料索引

## 资料类型

当前收录内容包括但不限于：

- 官方教程截图
- 脚本界面截图
- 组件说明与功能资料
- 编辑器界面与逻辑相关内容
- 对象结构、属性、数据类型、结构体等信息
- 引擎更新说明、版本更新记录、修复内容
- 玩家或社区整理的分析文本与经验资料
- 其他与创游世界相关、具有归档与检索价值的内容

## 面向 AI 的整理目标

为了便于后续将资料用于 AI 学习、知识检索或辅助问答，本仓库会尽量朝以下方向整理：

- 尽可能保留原始资料
- 尽可能进行分类归档
- 尽可能统一命名与目录结构
- 尽可能提高可检索性
- 为后续 OCR、文本提取、标签整理、结构化处理提供基础

## 使用场景

本仓库适合用于：

- 构建创游世界相关的 AI 知识库
- 作为 RAG 检索语料或问答参考资料
- 辅助整理脚本、组件、编辑器和对象结构相关知识
- 为后续自动分类、文本抽取、语义搜索提供基础数据
- 供创作者、研究者和学习者查阅参考

# 创游世界资料汇总

一个面向 **AI 检索、知识整理、学习研究与长期维护** 的创游世界资料仓库。

本仓库主要收集、归档并持续整理与创游世界相关的各类资料，内容涵盖脚本、组件、编辑器界面、对象结构、引擎更新、教程截图及其他可用于学习、分析、检索和知识构建的信息。目标不只是“存资料”，而是把分散内容整理成 **可导航、可追溯、可检索、可持续扩写** 的知识库。

- 作为创游世界相关资料的长期归档库
- 作为 AI 问答、知识库、RAG 检索的基础语料

为了便于后续将资料用于 AI 学习、知识检索或辅助问答，本仓库持续朝以下方向整理：

- 尽可能保留原始资料
- 尽可能进行分类归档
- 尽可能统一命名与目录结构
- 尽可能提高可检索性
- 为 OCR、文本提取、标签整理、结构化处理提供基础
- 让大多数结论都能反向回溯到截图、OCR 或专题文档

## 6. 当前整理方法

仓库当前主要采用以下整理链路：

1. 保留原始截图、文本和更新说明
2. 对截图进行 OCR 与主题编号映射
3. 将高价值证据整理为专题文档
4. 用总索引、标签体系和待验证清单维护全局结构
5. 持续把“研究线索”升级为“有证据支撑的结论”

这意味着：
- 有些文档已经是较成熟专题
- 有些仍处于“证据不足但研究价值高”的状态
- 仓库会明确区分“直接证据”“多来源归纳”“社区推测”“待验证”

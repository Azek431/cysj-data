## 核心概念速查

| 概念 | 解释 |
|------|------|
| **素材** | 资源模板，放入地图后变为物体 |
| **物体** | 素材在地图中的实例 |
| **组件** | 赋予物体能力的模块（属性+指令+事件） |
| **脚本** | 用积木块组合组件能力 |
| **广播** | 跨物体通知消息的事件机制 |
| **局部变量** | 单次脚本内的临时数据 |
| **玩家变量** | 跨会话的持久化数据 |
| **配置表** | 静态规则与策划数据 |
| **地图属性** | 当前地图的全局数据 |
| **系统属性** | 整个游戏的全局数据 |

## 常见问题

**Q：脚本和组件是什么关系？**
A：组件是能力的封装（属性+指令+事件），脚本是用积木块调用这些能力的方式。

**Q：广播和变量有什么区别？**
A：广播是事件通知机制，用于响应式逻辑；变量是数据存储机制，用于状态管理。两者配合使用。

**Q：局部变量和玩家变量有什么区别？**
A：局部变量仅在单次脚本执行中存在，执行完就消失；玩家变量会持久化到云端，可跨会话使用。

**Q：如何选择数据存储位置？**
A：临时计算用局部变量；玩家状态用玩家变量；静态规则用配置表；地图级共享数据用地图属性；全游戏共享数据用系统属性。

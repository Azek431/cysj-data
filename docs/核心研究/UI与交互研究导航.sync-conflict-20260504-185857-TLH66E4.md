## 这组文档重点回答什么
- UI 到底只是显示层，还是也能承载逻辑
- 背包、商店、任务、弹窗、状态栏为什么底层常常共享一套 UI 模式
- 格子 UI 的本质是什么
- 联机下 UI 为什么更容易出同步问题

## 常见误区
- `[已确认]` 不建议把 UI 当成长期真值唯一来源。
- `[已确认]` 不建议让 UI 和地图逻辑直接强耦合，最好通过广播或清晰的数据流连接。
- `[高可信推断]` 复杂项目里，UI 层越轻、地图层或系统层越稳定，整体越容易维护。

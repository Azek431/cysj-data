# 创游世界碰撞与物理系统入门

## 一句话摘要

创游世界的物理系统决定了物体之间如何相互作用。本文档讲解物理组件、碰撞检测、阻挡通行和刚体设置的核心概念，帮助你实现可移动的物体、障碍物和物理交互。

## 1. 物理系统概述

### 1.1 为什么需要物理系统

在创游世界中，如果一个物体没有物理组件：

- 它不会对其他物体产生阻挡
- 玩家角色无法与它碰撞
- 它可能无法正常移动
- 物理交互（如推箱子、障碍物）无法实现

物理系统是游戏互动的基础。

### 1.2 物理组件的位置

物理组件在对象编辑界面中，属于「通用」类组件：

- **物理**：赋予物体物理属性
- **阻挡通行**：让物体阻挡其他物体移动

---

## 2. 物理组件详解

### 2.1 物理组件

物理组件赋予物体「物理存在」的能力。

**核心参数**：

| 参数 | 说明 | 备注 |
|------|------|------|
| 类型 | 刚体类型（静态/动态） | 影响物体如何响应外力 |
| 质量 | 物体质量 | 影响碰撞力度 |
| 阻力 | 移动阻力 | 影响滑动距离 |
| 弹性 | 碰撞弹性 | 影响弹跳效果 |

**使用场景**：
- 需要被推动的物体（箱子、木桶）
- 需要有物理反应的物体（弹球、弹射物）
- 需要模拟重力效果的对象

### 2.2 阻挡通行组件

阻挡通行组件让物体具有「阻挡其他物体」的能力。

**类型**：

| 类型 | 说明 | 典型用途 |
|------|------|----------|
| 完全阻挡 | 任何物体都无法通过 | 墙壁、障碍物 |
| 部分阻挡 | 根据条件决定是否阻挡 | 可破坏的墙 |
| 特定对象阻挡 | 只阻挡特定类型 | 只阻挡玩家的门 |

**使用场景**：
- 墙壁、围栏、门窗
- 需要阻挡玩家但允许子弹通过的栅栏
- 需要根据游戏状态改变阻挡属性的机关

## 3. 碰撞检测

### 3.1 什么是碰撞检测

碰撞检测是检测两个物体是否「接触」的技术。当两个物体发生碰撞时，可以触发相应的事件。

### 3.2 创游世界中的碰撞事件

在脚本中，可以通过「当碰撞时」触发时机来响应碰撞：

```
当碰撞时：
  → 获取碰撞对象
  → 判断碰撞对象类型
  → 执行相应逻辑
```

### 3.3 碰撞检测的典型应用

| 应用场景 | 实现方式 | 示例 |
|----------|----------|------|
| 伤害触发 | 子弹碰撞玩家 | 伤害判定 |
| 拾取物品 | 玩家碰撞道具 | 获得道具 |
| 区域触发 | 玩家碰撞区域 | 触发机关 |
| 阻挡判定 | 移动时检测前方 | 寻路避障 |

## 4. 角色移动与物理

### 4.1 为什么角色能移动

角色能够移动通常需要以下组件：

1. **角色组件**：赋予物体「角色」属性，可以被玩家控制
2. **物理组件**：让角色具有物理存在
3. **阻挡通行**：设置阻挡区域，确保角色不会穿墙

### 4.2 角色走不动的常见原因

| 问题 | 检查项 | 解决方法 |
|------|--------|----------|
| 无法移动 | 角色组件是否挂载 | 添加角色组件 |
| 卡在原地 | 是否有阻挡通行冲突 | 检查阻挡关系 |
| 穿墙 | 阻挡通行组件设置 | 添加/调整阻挡设置 |
| 漂移 | 阻力设置 | 调整阻力数值 |

### 4.3 排查步骤

1. 检查物体是否挂载了角色组件
2. 检查物体是否挂载了物理组件
3. 检查周围是否有阻挡通行的物体
4. 检查物理组件的阻力值是否过大

## 5. 物理系统的常见误区

### 误区 1：只有物理组件就能移动

**错误**：
- 只有物理组件的物体不会自动移动
- 物理组件只是让物体「可以被物理影响」
- 需要角色组件才能被玩家控制

**正确理解**：
- 物理组件 → 物理存在（可被碰撞、被推开）
- 角色组件 → 可被玩家控制移动
- 两者配合才能实现角色移动

### 误区 2：所有物体都加阻挡通行

**错误**：
- 所有物体都加阻挡通行可能导致：
  - 地图加载变慢
  - 性能下降
  - 碰撞检测变复杂

**正确理解**：
- 只在需要阻挡的地方添加阻挡通行
- 道具、装饰物一般不需要阻挡
- 合理规划阻挡区域

### 误区 3：物理参数随意设置

**错误**：
- 阻力太大会让物体几乎无法移动
- 弹性太大会让物体弹跳失控
- 质量不匹配会导致碰撞效果不自然

**正确做法**：
- 参考常见游戏物理参数
- 根据需要微调
- 保持物理效果的一致性

## 6. 实战示例

### 示例：可拾取道具

```
物体：发光宝石
组件：物理（静态）、互动按钮

当接近时：
  显示提示 "按E拾取"

当互动按钮被按下时：
  发送广播 "获得宝石"
  播放拾取动效
  销毁自身
```

### 示例：可推动的箱子

```
物体：木箱
组件：物理（动态）、碰撞触发

当碰撞时：
  如果 碰撞对象 == 玩家：
    获取玩家移动方向
    移动箱子沿该方向
    播放推动音效
```

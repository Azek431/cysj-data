## 积木块分类速查

| 分类 | 示例 | 功能 |
|------|------|------|
| 动作类 | 移动、播放动画、销毁 | 控制物体行为 |
| 控制类 | 等待、循环、条件判断 | 控制执行流程 |
| 数据类 | 获取属性、设置变量 | 操作数据 |
| 事件类 | 发送广播、调用指令 | 触发其他逻辑 |
| 数学类 | 加减乘除、随机数 | 数学运算 |
| 逻辑类 | 且、或、非 | 逻辑判断 |

## 触发时机类型速查

| 类型 | 触发时机 | 触发条件 |
|------|----------|----------|
| 事件型 | 当被创建时 | 对象创建时 |
| 事件型 | 当被销毁时 | 对象销毁时 |
| 事件型 | 当受到伤害时 | 受到伤害时 |
| 交互型 | 当被点击时 | 被点击时 |
| 交互型 | 当互动按钮被按下时 | 玩家按下互动时 |
| 交互型 | 当接近时 | 玩家接近时 |
| 广播型 | 当收到广播时 | 收到指定广播时 |
| 循环型 | 重复执行直到 | 重复直到满足条件 |
| 条件型 | 当满足条件时 | 条件满足时 |

## 自定义组件三大元素

| 元素 | 说明 | 示例 |
|------|------|------|
| 属性 | 存储数据 | 数字1、文本1 |
| 指令 | 可调用的行为入口 | 当执行"指令1"时 |
| 触发时机 | 响应事件 | 当被创建时、当受到伤害时 |

## 当前可确认的API观察框架

- `[已确认]` 创游世界的"API"并不完全等同于传统代码函数表。
- `[已确认]` 更接近"组件 + 属性 + 指令 + 触发时机 + 作用域 + 动作块"的复合接口系统。
- `[已确认]` 自定义组件是API化程度最高、最适合整理成接口视角的一类内容。
- `[待验证]` 仍有部分OCR低清页、未逐图补齐的接口项，不能宣称已经做到全量完整手册。

## 一句话摘要

本文档汇总创游世界脚本系统相关的高价值文档，帮助你快速找到脚本界面、积木知识、组件能力、作用域、数据流、项目结构等核心入口。

如果你想知道：
- 创游世界脚本系统到底由哪些部分组成
- 新手应该先读哪些脚本文档
- 做项目时脚本、作用域、广播、UI、系统层应该怎么配合
- API、参数、指令、触发时机这些内容分别去哪看

可以先从这页开始。

## 常见误区
- 不要把“脚本系统”只理解成积木拼接，它本质上还包括组件能力、作用域分层、事件驱动和项目结构。
- 不要把所有值都放在一个地方，作用域分层是可维护性的关键。
- 不要把 API 清单当成全部知识，真正实战还需要配合 UI、广播、数据结构与系统层理解。

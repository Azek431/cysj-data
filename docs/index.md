## 站点定位

`cysjdocs.dpdns.org` 是 `Azek431/cysj-data` 的官方配套知识库，面向创游世界引擎全用户场景：

- **0基础新手**：用最少时间理解基本概念和实战路径。
- **资深创作者**：获取脚本、UI、项目结构和版本演进分析。
- **AI检索开发者**：获取结构化索引、证据链和可追溯语料。
- **社区维护者**：查看贡献规范、运维方案和长期维护计划。

## 核心优势

- **结构与仓库同步**：所有核心模块与 `docs/` 目录一一对应。
- **可追溯证据链**：OCR 文本、图片编号映射、专题结论三段式回链。
- **全站可用导航**：顶部导航、侧边栏、目录锚点、上一页/下一页、编辑链接。
- **合规与维护**：内置版权声明、贡献指南、风险提示和运维预案。

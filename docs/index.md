## 为什么选择这个知识库

这是一个面向“可导航、可追溯、可检索、可贡献”的创游世界资料库。它不仅保留原始资料与 OCR 文本，还为后续 AI 检索、专题复盘、问题验证提供清晰的入口。

- **快速定位**：通过精选导航与主题入口，避免在海量资料中迷失。
- **证据可追溯**：优先展示 OCR 来源、映射路径与研究结论。
- **模块化阅读**：将脚本、UI、项目设计、OCR、维护分成独立模块，降低学习成本。
- **社区友好**：支持一键编辑、反馈和 GitHub issue 贡献。

## 这个资料库适合谁？

如果你正在学习、整理或研究「创游世界」，这个资料库可以作为长期参考入口。

你可以把它当成：

- **新手学习路线**：从基础概念、教程资料、脚本系统开始逐步阅读。
- **脚本机制索引**：快速查找变量、广播、事件、组件、UI、API 等相关内容。
- **项目设计参考**：整理游戏系统、商店、多地图、引导流程和项目结构设计思路。
- **OCR 证据库**：保存截图识别、编号映射、缺失清单和资料完整化状态。
- **维护记录中心**：记录哪些内容已整理、哪些内容待验证、哪些内容需要继续补全。

## 资料可信度说明

本资料库会尽量区分不同来源和整理状态：

| 类型 | 含义 |
|---|---|
| 原始资料 | 来自截图、OCR、界面内容或原始记录 |
| 整理资料 | 对多个原始信息进行归纳、分类和结构化 |
| 研究结论 | 基于现有资料进行分析、推理和总结 |
| 待验证内容 | 暂时无法完全确认，后续需要继续补证 |

这样做的目的不是让资料看起来复杂，而是让每个结论都尽量做到：

> 有来源、有状态、可追溯、可继续维护。

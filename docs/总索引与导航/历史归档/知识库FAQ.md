## 一句话摘要

本文解答关于创游世界知识库（cysj-data）的常见问题，帮助用户快速上手使用本站、了解贡献流程、识别文档可信度等级，并知道遇到问题时如何反馈。

## 关于知识库本身

### Q：这个知识库是什么？

**A**：创游世界知识库（cysj-data）是由 Azek431 维护的开源资料库，旨在系统整理创游世界引擎的脚本系统、UI设计、项目架构、OCR证据、引擎更新、社区分析和维护报告。所有内容托管在 GitHub 上，基于 MIT 许可证开源。

### Q：知识库和官方教程是什么关系？

**A**：知识库不是官方文档，而是社区整理的资料库。内容来源于官方教程截图、社区分享、OCR转写和个人研究归纳，目标是帮助用户更高效地学习和检索创游世界相关知识。

### Q：知识库的内容可信吗？

**A**：知识库中的每篇文档都标注了「证据等级」：

| 证据等级 | 含义 |
|----------|------|
| **E1 直接证据** | 官方截图、官方教程原文、官方更新说明 |
| **E2 OCR/转写证据** | 截图 OCR 转写，需人工复核 |
| **E3 归纳结论** | 多来源交叉验证后的合理结论 |
| **E4 社区经验/推测** | 社区经验或合理推断，未必完全准确 |
| **待验证** | 证据不足，需要进一步验证 |

### Q：知识库的更新频率是怎样的？

**A**：知识库是持续维护项目，会根据引擎更新、社区反馈和 OCR 进展不定期更新。更新日志记录在「维护与报告」目录下。

## 文档结构说明

### Q：文档分类是怎么划分的？

**A**：知识库分为以下主要分类：

| 分类 | 内容 |
|------|------|
| **总索引与导航** | 首页、新手路线、知识库总导航、使用指南 |
| **教程资料** | 官方教程索引、学习路线、速查指南 |
| **核心研究** | 脚本、变量、广播、组件、UI、碰撞、联机 |
| **脚本系统** | 脚本编辑器、积木块、API整理、命名规范 |
| **项目设计** | 商店、背包、地图、任务、道具、存档 |
| **OCR资料** | 截图转文本、映射表、证据链说明 |
| **引擎更新** | 版本演进、4.54.0特性、联机UI |
| **社区分析** | 用户解析、待验证问题 |
| **维护与报告** | 贡献指南、运维方案、更新日志 |
| **元信息** | 术语表、标签体系、文档状态 |

### Q：什么是 OCR 资料？为什么有些内容标注了 OCR？

**A**：OCR（光学字符识别）资料是指创游世界官方教程截图通过 OCR 工具转写的文本。这些内容对研究有价值，但 OCR 识别可能存在错误，所以需要标注「E2 OCR/转写证据」并说明需要人工复核。详见 [OCR资料导航](/OCR资料/OCR资料导航.md)。

### Q：什么是「待验证」内容？

**A**：如果某条信息证据不足，或者只来自社区经验而非官方确认，会标注为「待验证」。这些内容在实际开发中需要自行测试确认，不能完全当作官方结论使用。

## 贡献与反馈

### Q：我想反馈文档错误或补充内容，应该怎么做？

**A**：有三种方式：

1. **GitHub Issue**：在 [cysj-data 仓库](https://github.com/Azek431/cysj-data/issues) 创建 Issue，描述问题或建议
2. **GitHub 编辑**：点击每页文档右上角的「在 GitHub 上编辑此页」，直接提交修改
3. **联系维护者**：通过 GitHub 仓库的联系信息找到维护者

### Q：提交内容有什么规范吗？

**A**：有的，详见 [社区贡献与维护指南](/维护与报告/社区贡献与维护指南.md)。主要规范包括：

- 不要编造不存在的官方 API、功能、版本特性
- 不要把推测写成事实
- OCR 内容必须标注证据等级
- 不确定内容必须标注「待验证」
- 遵守 VitePress 文档格式要求

### Q：OCR 资料可以参与整理吗？

**A**：可以。OCR 资料是知识库的重要组成部分，需要持续的人工复核和整理。详见 [OCR资料导航](/OCR资料/OCR资料导航.md) 了解当前 OCR 进展和参与方式。

## 技术与部署

### Q：这个知识库是用什么技术搭建的？

**A**：基于 VitePress 构建，托管在 GitHub，主站部署在 Cloudflare Pages，同时有 Gitee 镜像。

### Q：知识库是开源的吗？

**A**：是的，基于 MIT 许可证开源，可以自由使用、修改和分发，但请遵守许可证条款。

### Q：如何本地运行知识库？

**A**：本地运行步骤：

```bash
# 克隆仓库
git clone https://github.com/Azek431/cysj-data.git

# 进入项目
cd cysj-data

# 安装依赖
pnpm install

# 本地预览
pnpm run docs:preview
```

## 关于创游世界引擎

### Q：创游世界是什么？

**A**：创游世界是一款面向普通用户的游戏创作工具，提供可视化编辑器、脚本系统（积木块）、组件系统、UI系统和联机功能，让没有编程经验的人也能制作游戏。

### Q：创游世界支持哪些平台发布？

**A**：创游世界支持发布到手机（Android/iOS）和网页端。具体支持情况请以官方最新说明为准。

### Q：创游世界最新版本是什么？

**A**：根据知识库收录的资料，当前已知最高版本为 4.54.0（及其对应版本标识）。详细的版本演进历史请查阅 [创游世界引擎更新演进简史](/引擎更新/创游世界引擎更新演进简史.md)。

### Q：在哪里下载创游世界编辑器？

**A**：请访问创游世界官方平台下载，下载链接以官方渠道为准，知识库不提供下载链接。

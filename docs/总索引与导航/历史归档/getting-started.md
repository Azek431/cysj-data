## 核心概念速查

如果你是第一次接触创游世界，先了解这四个核心概念：

| 概念 | 一句话解释 |
|------|----------|
| **素材** | 放在地图前的模板资源，包含贴图和可挂载的组件 |
| **物体** | 素材放到地图后的实例，有独立的状态和行为 |
| **组件** | 赋予物体能力的模块，决定物体能做什么 |
| **脚本** | 用积木块拼装的行为逻辑，决定物体何时执行什么操作 |

详细解释请查看：[核心概念速查手册](/核心研究/核心概念速查手册)

## 快速问题速查

| 问题 | 快速答案 |
|------|---------|
| 角色走不动 | 检查是否挂了「角色组件」+「物理组件」 |
| 改了素材地图没变 | 使用「应用到原素材」或重新摆物体 |
| 脚本不执行 | 检查触发时机、名称是否正确 |
| 广播没效果 | 检查名称、监听触发时机、对象是否存活 |
| UI 找不到 | 确认是哪种 UI，去对应设置找 |
| 变量值丢失 | 检查变量作用域是否正确 |
| 循环卡死 | 添加等待语句 |
| 背包满 | 最大 200 格 |

详细解答请查看：[创游世界新手常见问题速查](/教程资料/创游世界新手常见问题速查)

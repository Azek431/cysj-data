## 基础问题
### Q1：这个知识库是什么？
**A**：创游世界资料库（cysj-data）是由 Azek431 维护的创游世界引擎非官方资料库，旨在为创游世界用户提供全面的学习资源、系统解析和开发参考。
**涵盖内容**：
- 脚本系统与积木能力
- 组件与对象体系
- UI 设计与管理
- 项目架构与系统设计
- OCR 截图转文本资料
- 引擎版本更新记录
- 社区分析与待验证问题
---
### Q2：知识库和创游世界官方是什么关系？
**A**：这是非官方的社区维护项目，不是创游世界官方产品。内容来源于官方教程、社区分享和个人整理，仅供学习参考使用。
---
### Q3：这个知识库是免费的吗？
**A**：是的。知识库基于 MIT 许可证开源，任何人都可以免费查看、使用和贡献。

## 文档规范问题
### Q12：文档中标注的「E1」「E2」「E3」「E4」是什么意思？
**A**：这是证据等级标注，表示内容的可靠程度：
| 等级 | 说明 |
|------|------|
| **E1** | 直接证据（官方截图、官方文档） |
| **E2** | OCR/转写证据（截图转文本） |
| **E3** | 归纳结论（多来源交叉验证） |
| **E4** | 社区经验/推测（待验证） |
---
### Q13：文档中标注的「待验证」是什么意思？
**A**：「待验证」表示该内容尚未得到直接证据支撑，可能存在不确定性。使用时需要自己判断，或等待后续验证。
---
### Q14：文档状态「草稿」「整理中」「已复核」是什么意思？
**A**：这是文档的完成度状态：
| 状态 | 说明 |
|------|------|
| 草稿 | 仅有初步结构，待补充内容 |
| 整理中 | 正在整理，内容可能不完整 |
| 已结构化 | 结构完整，内容基本完善 |
| 待验证 | 核心内容需要验证 |
| 已复核 | 已通过人工复核 |
| 持续维护 | 长期更新维护 |
---
### Q15：我写的文档怎样才能被接受？
**A**：请确保：
1. 符合 [资料规范与状态总览](/维护与报告/资料规范与状态总览) 的要求
2. 使用标准的 frontmatter 元数据
3. 遵循 [文档格式规范](/维护与报告/创游世界知识库文档格式规范)
4. 内容真实准确，不编造信息
5. 区分官方资料和社区经验

## 当前结构说明

- `[已确认]` 现阶段主入口已经迁移为中文目录聚合结构，旧英文目录名仅作为历史迁移口径保留在少量说明中。
- `[已确认]` 核心内容当前主要按中文分类存放，例如 `教程资料 / 脚本系统 / 引擎更新 / 社区分析 / OCR资料 / 元信息`。
- `[已确认]` 新增的中文目录主要负责：
  - 给玩家提供更直观的入口
  - 给 AI 提供更稳定的聚合页
  - 给后续重构提供清晰分类框架
- `[高可信推断]` 后续如果继续深修，最值得投入的方向是：继续补专题页头部、继续补 OCR 回链、继续完善项目设计类栏目页。

# 新手阅读路线

[[toc]]

## 如果你是第一次接触这套资料

建议按这个顺序读：

### 第一步：先建立整体认知
1. `docs/教程资料/专题研究/创游世界学习路线图.md`
2. `docs/教程资料/专题研究/创游世界对象_素材_组件_脚本关系总图.md`

你先别急着看特别细的脚本细节，先弄懂这些最基础的问题：
- 素材和物体是什么关系
- 组件是干什么的
- 脚本为什么总和组件、对象、UI 扯在一起
- 广播为什么在很多系统里都这么重要

### 第二步：理解脚本和广播
1. `docs/脚本系统/专题研究/脚本作用域与数据流深度研究.md`
2. `docs/教程资料/专题研究/广播机制深度解析.md`
3. `docs/脚本系统/专题研究/自定义组件深度解析.md`

重点理解：
- 变量和属性该放哪层
- 广播适合做什么，不适合做什么
- 自定义组件为什么有复用价值

### 第三步：开始看项目结构
1. `docs/脚本系统/专题研究/创游世界项目结构模板.md`
2. `docs/脚本系统/专题研究/创游世界脚本实战架构入门.md`
3. `docs/脚本系统/专题研究/创游世界新手常见卡点与避坑清单.md`

### 第四步：按你想做的功能继续看
- 想做战斗：看 `docs/脚本系统/专题研究/创游世界战斗系统设计入门.md`
- 想做背包/商店：看 `docs/脚本系统/专题研究/创游世界背包与货币系统设计入门.md`
- 想做 UI：看 `docs/脚本系统/专题研究/创游世界UI数据同步架构.md`
- 想做任务：看 `docs/脚本系统/专题研究/创游世界任务与事件系统设计入门.md`
- 想做交互：看 `docs/脚本系统/专题研究/创游世界交互系统设计入门.md`

## 新手最容易踩的坑

- `[已确认]` 一上来就只抄视频步骤，不理解数据放在哪层
- `[已确认]` 把 UI 当成真值层，后期越做越乱
- `[已确认]` 广播乱发、命名混乱，导致系统越来越难维护
- `[高可信推断]` 很多新手不是不会写功能，而是没有“最小可维护结构”的意识

## 看完这条路线后该做什么

建议你至少做一个最小练习项目：
- 一个角色
- 一个交互对象
- 一个 UI 面板
- 一个简单任务
- 一个广播刷新链路

这样你会比只看概念更快进入状态。

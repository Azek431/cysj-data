## 第一阶段：编辑器入门（1-3天）

### 学习目标

- 熟悉编辑器界面布局
- 掌握基本操作（创建、删除、选择、拖拽）
- 了解素材、物体、地图的概念
- 完成第一个可运行的游戏场景

### 核心知识点

| 知识点 | 说明 | 推荐文档 |
|--------|------|----------|
| 编辑器界面 | 素材面板、属性面板、地图编辑区 | [编辑器基础入门](../教程资料/创游世界编辑器基础入门.md) |
| 素材与物体 | 素材是模板，物体是实例 | [概念速查卡](../教程资料/创游世界概念速查卡.md) |
| 基本操作 | 创建、选择、删除、调整 | [快速上手清单](../教程资料/创游世界快速上手清单.md) |

### 快速上手步骤

1. **新建项目**：打开编辑器 → 新建项目 → 选择空白模板
2. **添加角色**：素材面板 → 角色分类 → 拖入地图
3. **设置玩家**：右键角色 → 设为玩家
4. **添加组件**：选中角色 → 添加物理组件 + 角色组件
5. **测试运行**：点击预览，确认角色可以移动

### 常见问题

| 问题 | 解决 |
|------|------|
| 角色不走动 | 检查是否同时挂了物理组件和角色组件 |
| 添加不了组件 | 检查素材类型是否支持该组件 |
| 地图找不到物体 | 检查图层是否被隐藏 |

> 📚 相关阅读：[创游世界核心概念速查](../核心研究/创游世界核心概念速查.md)

## 第二阶段：组件系统（3-7天）

### 学习目标

- 理解组件=能力的核心理念
- 掌握核心组件的使用方法
- 能够组合多个组件实现复杂功能
- 理解物理和碰撞的基本原理

### 核心组件一览

| 组件类型 | 作用 | 常见组件 |
|----------|------|----------|
| 物理组件 | 赋予物体物理能力 | 物理组件、角色组件 |
| 战斗组件 | 赋予战斗能力 | 伤害组件、子弹组件 |
| 交互组件 | 赋予交互能力 | 可互动组件、触发器组件 |
| 显示组件 | 赋予显示能力 | 动效组件、特效组件 |

### 组件组合示例

**移动角色**：
```
素材 + 物理组件 + 角色组件 = 可移动角色
```

**敌人**：
```
素材 + 物理组件 + AI组件 + 伤害组件 = AI敌人
```

**子弹**：
```
素材 + 物理组件 + 伤害组件 + 子弹组件 = 飞行子弹
```

### 物理与碰撞

**碰撞三要素**：
1. 两个物体都要有物理组件
2. 要设置正确的碰撞层级
3. 碰撞盒不能为 0

**碰撞层级配置**：
- 打开「游戏设置」
- 找到「碰撞层级」配置
- 设置物体之间的碰撞关系

> 📚 相关阅读：[创游世界碰撞与物理系统入门](../核心研究/创游世界碰撞与物理系统入门.md) - 物理系统详解

## 第三阶段：脚本入门（7-14天）

### 学习目标

- 理解触发时机是脚本的入口
- 掌握变量的创建和使用
- 理解广播机制进行对象通信
- 能够实现简单的游戏逻辑

### 触发时机速查

| 触发时机 | 触发条件 | 使用场景 |
|----------|----------|----------|
| 当开始时 | 物体被创建 | 初始化设置 |
| 当点击时 | 玩家点击物体 | 按钮交互 |
| 当碰撞时 | 与其他物体碰撞 | 碰撞检测 |
| 当收到广播时 | 收到指定广播 | 事件响应 |
| 当互动按钮被按下时 | 玩家按下互动按钮 | NPC对话 |

### 变量系统

**变量层级选择**：

| 变量类型 | 生命周期 | 适用场景 |
|----------|----------|----------|
| 局部变量 | 脚本执行完消失 | 临时计算 |
| 自身属性 | 物体存在期间 | 对象自身状态 |
| 地图属性 | 地图存在期间 | 同地图共享数据 |
| 系统属性 | 游戏全程 | 全局/跨地图数据 |
| 玩家变量 | 跨会话持久化 | 玩家相关数据 |

**记住原则**：
- 需要长期保存的数据 → 属性或玩家变量
- 临时计算 → 局部变量

### 广播机制

**广播是什么**：
- 广播是一种「发消息给多个对象」的事件通知机制
- 发送者不需要知道谁在监听
- 监听者通过订阅事件来接收并响应消息

**推荐架构**：
```
UI 操作
    ↓
发送广播（请求）
    ↓
地图/系统处理逻辑
    ↓
修改真值
    ↓
发送广播（通知）
    ↓
UI 更新显示
```

**广播命名规范**：
- ✅ 推荐：`开始挑战`、`打开背包`、`任务完成`
- ❌ 不推荐：`广播1`、`刷新`、`改值`

> 📚 相关阅读：[创游世界变量与作用域完全指南](../核心研究/创游世界变量与作用域完全指南.md) - 变量详解

## 第四阶段：进阶开发（14-30天）

### 学习目标

- 掌握UI系统的设计和使用
- 理解数据存储和存档机制
- 能够设计多地图切换
- 能够实现战斗系统

### UI系统

**三种UI类型**：

| UI类型 | 说明 | 使用场景 |
|--------|------|----------|
| 游戏UI | 整个游戏全局显示 | 血条、背包按钮 |
| 地图UI | 每个地图独立 | 任务提示、对话框 |
| 物体UI | 绑定到物体上 | 头顶血条、名字标签 |

**UI通信模式**：
```
UI发广播 → 地图处理 → 地图通知 → UI刷新
```

### 数据存储

**数据存储位置选择**：

| 数据类型 | 存储位置 |
|----------|----------|
| 临时计算 | 局部变量 |
| 某个对象状态 | 自身属性 |
| 当前地图共享 | 地图属性 |
| 全局数据 | 系统属性 |
| 玩家持久化 | 玩家变量（勾选云存储） |
| 静态配置 | 配置表 |

### 多地图管理

**地图切换方式**：
1. 使用「切换地图」积木
2. 使用传送门/触发器
3. 使用UI按钮切换

**跨地图数据**：
- 使用系统属性或玩家变量
- 避免使用地图属性（切换后会丢失）

## 第五阶段：联机与发布（30天+）

### 学习目标

- 理解联机系统的基本原理
- 掌握联机数据同步的方法
- 能够进行游戏测试和优化
- 能够发布和分享游戏

### 联机系统基础

**联机架构要点**：
1. UI只发一次广播，地图集中处理
2. 公共数据放系统属性或玩家变量
3. 玩家变量勾选云存储实现数据同步

**联机优化建议**：
- 更新到 4.52.54+ 版本
- 减少UI中的公共数据写操作
- 合并多个小操作为一个请求广播

### 测试与优化

**测试清单**：
- [ ] 单机功能测试
- [ ] 联机功能测试
- [ ] 不同设备兼容性测试
- [ ] 性能测试（帧率、内存）
- [ ] 边界情况测试

**常见优化方向**：
- 减少不必要的广播
- 优化碰撞检测范围
- 减少UI更新频率
- 合理使用等待语句

### 发布与分享

**发布前检查**：
1. 游戏是否有明显bug
2. 核心玩法是否完整
3. 是否有足够的内容
4. 引导是否清晰

**分享渠道**：
- 创游世界官方平台
- B站视频教程
- 社区论坛
- QQ/微信群

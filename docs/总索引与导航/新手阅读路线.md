# 新手阅读路线

[[toc]]

## 一句话摘要

本文为创游世界新手提供一条清晰的学习路径，帮助你从"不知道从哪开始"到"能独立完成简单项目"。

## 适合谁阅读

- 刚下载创游世界不知道从哪开始的新手
- 看了很多教程但还是不知道怎么做项目的学习者
- 想系统规划学习路线的创作者

## 你将学到什么

- 创游世界学习的正确顺序
- 每个阶段应该掌握的核心概念
- 如何从"看教程"过渡到"做项目"
- 新手最容易踩的坑及避坑方法

## 核心结论

1. **先建立概念体系**：素材→物体→组件→脚本→广播，理解这根链条比急着做功能更重要
2. **先学最小闭环**：从"角色能动"→"物体可交互"→"UI能显示"→"状态能保存"一步一步来
3. **先做再扩展**：不要一上来就想着做 RPG、联机游戏，从小闭环开始积累经验

### 第五步：完成第一个最小练习项目

建议做一个包含以下要素的最小练习项目：
- 一个可移动角色
- 一个交互对象（可点击或可接近）
- 一个 UI 面板（显示/隐藏）
- 一个简单任务（触发→完成→反馈）
- 一个广播刷新链路（UI 通知→地图处理→UI 刷新）

这样做会让你比只看概念更快进入状态。

## 新手最容易踩的坑

| 坑 | 说明 | 避坑方法 |
|---|------|----------|
| 不理解"显示"和"真值"的区别 | 把 UI 当成数据来源，切地图后数据丢失 | 真值放地图层或系统层，UI 只负责显示 |
| 所有逻辑都写在一个对象里 | 前期省事，后期耦合失控 | 按职责分层：角色逻辑/UI逻辑/地图逻辑 |
| 广播命名太随意 | 叫"刷新1""刷新2"，后期根本不知道是什么 | 用语义化命名："道具_获得"、"任务_完成" |
| 一上来就想做复杂系统 | 还没学会变量就想着数据库 | 先做最小闭环：一个按钮能点就行 |
| 只记步骤不记结构 | 换个素材/需求就不会了 | 记"为什么要这样做"而不是"点哪里" |

## 推荐的新手入门完整路径

如果你是完全零基础，建议按以下顺序学习：

```
第一阶段：建立概念（1-2天）

└── 组件系统完全指南

第二阶段：学会编辑器（1-2天）
├── 创游世界编辑器基础入门
├── 创游世界编辑器界面详解
└── 创游世界编辑器常用操作速查

第三阶段：学会脚本（3-5天）
├── 脚本入门完全指南
├── 广播机制深度解析
├── UI系统与切换机制解析
└── 变量与作用域完全指南

第四阶段：学会项目结构（3-5天）
├── 项目结构模板
├── 新手常见卡点与避坑清单
├── UI数据同步架构
└── 广播驱动项目结构实战

第五阶段：做第一个完整项目（5-7天）
├── 战斗系统设计入门
├── 背包与货币系统设计入门
└── 常见问题与避坑指南
```

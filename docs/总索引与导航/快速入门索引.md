# 快速入门索引

本文档为创游世界新手提供一条清晰的快速起步路径，帮助你在最短时间内建立核心认知并完成第一个可运行的简单项目。

## 一句话摘要

创游世界是一个可视化游戏编辑器，核心概念是「素材 → 物体 → 组件 → 脚本 → 广播」，掌握这个链条就能快速上手。

## 适合谁阅读

- 刚下载创游世界不知道怎么开始的新手
- 想快速了解创游世界能做什么的用户
- 需要一个清单式入口来规划学习路径的用户

## 核心认知速读（5 分钟）

在开始任何教程之前，先记住这 6 个核心概念：

| 概念 | 一句话解释 | 关键点 |
|------|-----------|--------|
| **素材** | 放在地图前的「模板」 | 修改素材不等于修改已摆放的物体 |
| **物体** | 素材放到地图后的「实例」 | 每个物体有独立状态 |
| **组件** | 赋予物体「能力」的模块 | 不挂组件 = 静态图片 |
| **脚本** | 决定物体「何时做什么」的逻辑 | 需要配合触发时机 |
| **广播** | 跨物体通知消息的机制 | 用于系统解耦 |
| **变量作用域** | 数据存放的四层结构 | 局部/自身/地图/系统 |

## 快速起步清单（按顺序执行）

### 第一步：认识编辑器

1. 阅读 [创游世界编辑器基础入门](/教程资料/创游世界编辑器基础入门.md)
2. 了解素材区、编辑区、组件区、脚本区、UI 区的基本布局

### 第二步：建立核心概念

1. 阅读 [核心概念速查手册](/核心研究/核心概念速查手册.md)
2. 重点理解：素材与物体的关系、组件的作用、脚本的执行方式

### 第三步：完成第一个练习项目

建议按以下顺序做练习：

#### 练习 1：让角色动起来

1. 添加一个角色素材到地图
2. 挂载「角色组件」
3. 挂载「物理组件」
4. 点击试玩

> 如果走不动 → 检查是否缺少角色组件或物理组件

#### 练习 2：创建一个可交互的物体

1. 添加一个素材到地图
2. 挂载「可互动物体」组件
3. 写脚本：当被点击时，播放声音或显示提示
4. 接近时会出现互动按钮

#### 练习 3：创建一个简单的 UI 面板

1. 创建一个地图 UI
2. 添加一个按钮
3. 写脚本：当按钮被点击时，发送广播
4. 在地图脚本中监听广播并执行相应操作

## 常见问题快速定位

| 问题 | 快速答案 |
|------|----------|
| 角色走不动？ | 检查角色组件 + 物理组件是否挂载 |
| 改了素材地图没变化？ | 素材≠物体，实例不会自动更新 |
| 广播没效果？ | 检查名称是否一致、监听脚本是否在正确触发时机下 |
| UI 切换找不到？ | 确认是地图UI、操作UI还是物体UI |
| 变量值丢失？ | 检查变量是否放在了正确的作用域层 |

## 新手最常踩的坑

1. **一上来就只抄视频步骤，不理解数据放在哪层**
2. **把 UI 当成真值层，后期越做越乱**
3. **广播乱发、命名混乱，导致系统越来越难维护**
4. **没有「最小可维护结构」的意识**

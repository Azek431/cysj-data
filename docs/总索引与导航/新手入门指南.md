## 一、编辑器界面概览

### 1.1 主界面结构

创游世界编辑器主要分为以下几个区域：

```text
┌─────────────────────────────────────┐
│            顶部工具栏               │
│  [保存] [试玩] [发布] [设置] 等      │
├─────────────────────────────────────┤
│                                     │
│           地图编辑区域              │
│      放置和编辑物体的主要区域        │
│                                     │
├──────────────┬──────────────────────┤
│   素材库     │      属性面板         │
│  素材分类    │   选中物体的属性      │
│  资源管理    │   组件和脚本编辑      │
│              │                      │
└──────────────┴──────────────────────┘
```

### 1.2 顶部工具栏

顶部工具栏提供常用操作入口：

| 按钮 | 功能 |
|------|------|
| 保存 | 保存当前工程 |
| 试玩 | 在编辑器内试运行游戏 |
| 发布 | 将游戏发布到平台 |
| 设置 | 游戏设置、联机设置等 |

### 1.3 素材库

左侧素材库按类型分类管理所有资源：

| 分类 | 说明 |
|------|------|
| 地块 | 用于铺设地面的素材 |
| 装饰 | 环境点缀类素材 |
| 角色 | 主角、NPC、敌人等 |
| 装置 | 功能性物体如机关、门等 |
| 道具 | 可拾取的物品 |
| 武器 | 角色可装备的武器 |
| UI素材 | 界面相关素材 |

### 1.4 属性面板

右侧属性面板显示当前选中物体的属性，可以：
- 查看和修改物体属性
- 添加或编辑组件
- 编写脚本逻辑

## 二、四大核心概念

在开始使用编辑器之前，需要先理解四个核心概念：

### 2.1 素材

**素材**是放到地图前的模板资源，包含贴图和可挂载的组件配置。

**关键特点**：
- 素材不是物体，而是物体的「设计图纸」
- 拖入地图后会生成物体实例
- 修改素材后，地图中的已有物体不会自动更新

### 2.2 物体

**物体**是放置在地图中的实际对象，是素材的实例化结果。

**关键特点**：
- 每个物体都是独一无二的实例
- 可以单独修改而不影响其他同素材物体
- 拥有自己的状态和属性

### 2.3 组件

**组件**是给物体赋予「能力」的模块。

**关键特点**：
- 贴图决定「看起来像什么」
- 组件决定「能做什么」
- 不挂组件的物体只是静态图片

**六大分类**：

| 分类 | 示例组件 | 主要功能 |
|------|----------|----------|
| 通用 | 物理、阻挡通行、物体UI | 基础交互能力 |
| 战斗 | 生命、伤害、武器槽、子弹 | 战斗相关能力 |
| 装置 | 机关、机关门、机关地板 | 机关设计 |
| 显示 | 粒子特效、动效 | 视觉效果 |
| 交互 | 移动摇杆、技能摇杆、互动按钮 | 用户输入 |
| 自定义 | 自定义组件 | 自定义功能 |

### 2.4 脚本

**脚本**是用积木块拼装的行为逻辑，决定对象在「什么时机下」做「什么操作」。

**基本结构**：
```
触发时机 + 积木块组合 = 脚本
```

**常见触发时机**：
- 当被创建时
- 当被点击时
- 当收到广播时
- 当受到伤害时
- 当死亡时

## 三、基础操作教程

### 3.1 导入素材

**操作步骤**：
1. 在素材库中找到对应分类（地块/装饰/角色等）
2. 点击分类最左边的蓝色 `+` 按钮
3. 选择导入方式（拍照/相册/文件等）
4. 等待素材导入完成

**小技巧**：
- 素材多时，可以创建文件夹进行整理
- 长按拖拽可以快速把素材移入文件夹

### 3.2 放置物体

**操作步骤**：
1. 在素材库中选择需要的素材
2. 点击或拖拽到地图编辑区域
3. 素材被放置后变成「物体」

**注意事项**：
- 拖入地图的那一刻，素材被「实例化」成物体
- 实例化时会记录当时的属性配置
- 后续修改素材模板，不会自动更新已摆放的物体

### 3.3 给物体添加组件

**操作步骤**：
1. 选中地图中的物体
2. 在右侧属性面板中找到「添加组件」
3. 选择需要的组件类型
4. 配置组件参数

**组件选择原则**：
- 想让物体能动 → 添加「物理组件」+「角色组件」
- 想让物体有血量 → 添加「生命组件」
- 想让物体可交互 → 添加「可互动组件」
- 想让物体显示界面 → 添加「物体UI组件」

### 3.4 编写脚本

**操作步骤**：
1. 选中需要添加脚本的物体
2. 在右侧属性面板中点击「写脚本」或「编辑脚本」
3. 进入脚本编辑器界面
4. 选择触发时机
5. 用积木块组合逻辑
6. 保存脚本

**脚本编辑器界面**：
```text
┌─────────────────────────────────────┐
│  触发时机选择                        │
│  [当被创建时 ▼]                      │
├─────────────────────────────────────┤
│                                     │
│         积木块编辑区域               │
│                                     │
│    ┌──────────┐  ┌──────────┐      │
│    │  变量    │  │  控制    │      │
│    └──────────┘  └──────────┘      │
│    ┌──────────┐  ┌──────────┐      │
│    │  动作    │  │  广播    │      │
│    └──────────┘  └──────────┘      │
│                                     │
└─────────────────────────────────────┘
```

### 3.5 地图层级调整

**操作步骤**：
1. 选中地图中的物体
2. 在属性面板中找到「层级」设置
3. 调整物体的显示层级

**层级说明**：
- 地块层级最低，通常在最下方
- 角色层级中等
- UI层级最高，显示在最上层

## 四、常见问题与解决

### Q1：角色在地图里走不动

**原因**：可能缺少必要的组件。

**解决方法**：
1. 选中玩家角色物体
2. 添加「物理组件」
3. 添加「角色组件」
4. 检查地块是否有「阻挡通行」设置

### Q2：找不到做好的UI

**原因**：三种UI的切换入口不同。

**解决方法**：
- 地图UI → 地图UI设置
- 操作UI → 操作UI设置
- 物体UI → 需要先给物体挂「物体UI组件」

### Q3：素材改了，地图里却没变化

**原因**：地图里的物体是实例，不是素材本身。

**解决方法**：
- 方案1：删掉旧物体，用新素材重新摆
- 方案2：选中地图物体 → 「应用到原素材」同步配置

### Q4：脚本不执行

**检查三点**：
1. 是否设置了正确的触发时机
2. 是否有语法错误（条件写错、变量名写错）
3. 执行时机是否在监听者初始化之后

### Q5：广播发出去没有效果

**常见原因**：
1. 广播名称写错了（注意大小写）
2. 监听脚本没有在「当收到广播时」触发时机下
3. 监听者在广播发送时已经被销毁

## 五、新手练习项目

建议新手完成的第一个练习项目包含以下要素：

### 5.1 最小闭环练习

| 练习 | 学会什么 |
|------|----------|
| 放置一个角色并让它能移动 | 物理组件 + 角色组件 |
| 放置一个可交互物体 | 可互动组件 + 脚本 |
| 实现UI显示/隐藏 | UI切换 + 广播 |
| 完成一个简单任务 | 触发→判定→反馈 |

### 5.2 推荐的第一个完整项目

做一个包含以下要素的小游戏：
- 一个可移动角色
- 一个交互对象（可点击或可接近）
- 一个UI面板（显示/隐藏）
- 一个简单任务（触发→完成→反馈）
- 一个广播刷新链路（UI通知→地图处理→UI刷新）

这样做会让你比只看概念更快进入状态。

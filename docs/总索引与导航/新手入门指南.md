# 新手入门指南

## 一句话摘要

本文档帮助第一次接触创游世界的用户快速建立基础认知，了解编辑器界面、核心概念和第一个游戏的搭建思路。

## 1. 创游世界是什么

创游世界是一个可视化游戏创作引擎，不需要写代码，通过拖拽积木块就能制作游戏。

**核心特点：**
- 可视化编辑器，手机上就能做游戏
- 不需要编程基础
- 内置素材库和组件系统
- 支持联机多人游戏
- 积木块脚本系统

---

## 2. 编辑器界面布局

创游世界的编辑器主要分为以下几个区域：

| 区域 | 功能 |
|------|------|
| 素材库 | 管理所有游戏资源（角色、道具、装饰等） |
| 地图编辑区 | 摆放物体、构建游戏场景 |
| 组件面板 | 给物体添加功能组件 |
| 脚本编辑器 | 用积木块编写行为逻辑 |
| UI 编辑器 | 制作游戏界面（按钮、文本、血条等） |

---

## 3. 四个核心概念

在创游世界里，有四个最基础的概念必须先理解：

### 3.1 素材

**素材 = 游戏资源的模板**

素材是放在素材库里的资源，包括：
- 角色
- 道具
- 装饰物
- 地块
- 武器

**关键点：** 素材本身不会出现在游戏里，它只是"设计图纸"。

### 3.2 物体

**物体 = 素材在地图上的实例**

当你把素材拖到地图上，就生成了一个"物体"。

**关键点：**
- 素材改动了，地图上已有的物体不一定跟着变
- 每个物体都是独立的，可以单独修改

### 3.3 组件

**组件 = 赋予物体能力的模块**

组件决定了一个物体"能做什么"：

| 组件类型 | 能做什么 |
|---------|---------|
| 物理组件 | 让物体可以移动、受力 |
| 角色组件 | 让物体成为可操控角色 |
| 生命组件 | 让物体有血量、能受伤 |
| 可互动组件 | 让物体可以被玩家交互 |
| 武器槽组件 | 让物体可以装备武器 |

**关键点：** 不挂组件的物体只是一个静态图片，不会动。

### 3.4 脚本

**脚本 = 用积木块写的行为逻辑**

脚本决定了一个物体在"什么时候"做"什么事"：

```
当被点击时
→ 播放动画
→ 向地图发广播 "我被点击了"
```

**关键点：** 脚本要挂在物体上才能执行。

---

## 4. 关系总结

这四个概念的关系：

```
素材（模板）
   ↓ 拖到地图
物体（实例）
   ↓ 挂载组件
物体获得能力
   ↓ 编写脚本
物体有了行为
```

## 5. 第一个练习：让角色动起来

### 步骤 1：创建玩家角色

1. 打开素材库
2. 选择一个角色素材
3. 点击"添加玩家"，放到地图中央

### 步骤 2：检查组件

如果角色素材没有自带组件，需要手动添加：

1. 选中地图上的角色
2. 打开组件面板
3. 添加"物理组件"（让角色可以移动）
4. 添加"角色组件"（让角色可以被操控）

### 步骤 3：试玩测试

点击"试玩"，用方向键或摇杆控制角色移动。

**如果角色不动，检查：**
- 是否挂了"物理组件"
- 是否挂了"角色组件"
- 地图地块是否有"阻挡通行"属性

---

## 6. 第二个练习：创建可交互物体

### 步骤 1：放一个物体

1. 从素材库拖一个物体到地图上
2. 选中这个物体

### 步骤 2：添加组件

1. 打开组件面板
2. 添加"可互动"组件
3. 设置互动按钮显示的文字（如"调查"）

### 步骤 3：编写脚本

1. 点击"写脚本"
2. 选择触发时机："当互动按钮被按下时"
3. 添加积木块：

```
当互动按钮被按下时
→ 播放动效 调查动画
→ 显示文字 "这里什么都没有..."
```

### 步骤 4：试玩测试

走到物体附近，按下互动按钮，查看效果。

---

## 7. 第三个练习：简单的广播通信

### 目标

当玩家点击按钮时，触发另一个物体的行为。

### 步骤 1：放两个物体

- 物体 A：按钮（添加"可互动"组件）
- 物体 B：门（添加"开关"组件，设置为"关闭"）

### 步骤 2：给按钮写脚本

```
当互动按钮被按下时
→ 向当前地图发广播 "打开门"
```

### 步骤 3：给门写脚本

1. 选中门
2. 点击"写脚本"
3. 选择触发时机："当收到广播时"
4. 填写广播名称："打开门"
5. 添加积木块：

```
当收到广播 "打开门" 时
→ 打开开关
→ 播放动效 开门动画
```

### 步骤 4：试玩测试

点击按钮，门应该会打开。

## 8. 最小练习项目建议

学完上面三个练习后，建议做一个最小练习项目：

| 组成部分 | 内容 |
|---------|------|
| 角色 | 一个可移动的玩家 |
| 地图 | 包含几个可互动的物体 |
| 交互 | 按钮触发事件 |
| 反馈 | 文字显示、动效播放 |
| 广播 | 两个物体通过广播通信 |

## 9. 常见问题

### Q：为什么角色走不动？

**A：** 检查：
1. 是否挂了"物理组件"
2. 是否挂了"角色组件"
3. 地块是否有"阻挡通行"属性

### Q：为什么改了素材，地图里没变化？

**A：** 地图里的物体是实例，不会自动跟随素材更新。

**解决方法：**
- 删除旧物体，用新素材重新摆放
- 或选中物体 → "应用到原素材"

### Q：为什么脚本不执行？

**A：** 检查：
1. 是否选择了正确的触发时机
2. 脚本名称是否写错
3. 监听者是否在广播发送时存在

### Q：为什么按钮不显示？

**A：** "互动按钮"只在玩家接近"可互动物体"时显示。如果想做常驻按钮，使用普通"按钮"组件。

## 10. 下一步学习方向

掌握基础后，建议按这个顺序继续学习：

1. **理解变量和数据层**
   - 学习"局部变量"和"属性"的区别
   - 了解数据该放在哪一层

2. **深入理解广播**
   - 广播不只是"发消息"
   - 它是系统解耦的关键工具

3. **学习 UI 系统**
   - 地图 UI、操作 UI、物体 UI 的区别
   - UI 只负责显示，真值放在玩法层

4. **做完整系统**
   - 血条系统
   - 背包系统
   - 商店系统

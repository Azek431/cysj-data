# docs 目录分类对照表
[[toc]]
## 1. 文档目的
本文档解释 `docs/` 目录下每个子目录的定位、核心作用与代表文档，帮助你快速找到适合的内容。

## 2. 目录结构一览
```
docs/
├── 总索引与导航/     # 首页入口、新手路线、全库导航
├── 教程资料/         # 官方教程、学习路线、素材与组件关系
├── 脚本系统/         # 脚本界面、积木能力、作用域、组件系统
├── 核心研究/         # API、变量、广播、UI、组件系统专题导航
├── 项目设计/         # 项目结构、系统设计、教程引导
├── OCR资料/          # 截图转文本、映射表、证据链
├── 引擎更新/         # 版本能力变化、联机演进
├── 社区分析/         # 社区观察、待验证问题
├── 维护与报告/       # 维护规范、更新日志、问题清单
├── 元信息/           # 术语表、标签体系、文档状态
├── guide/            # VitePress 默认示例文档
├── AI优化输出/       # AI 优化相关输出内容
└── 待整理/           # 临时待整理区域（空目录）
```

## 3. 各目录详细说明

- docs 目录分类对照表

**代表文档**：
- `新手阅读路线.md` - 新手入门第一步

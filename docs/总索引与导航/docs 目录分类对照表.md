# docs 目录分类对照表

一句话摘要：这份文档用来说明当前 `docs/` 中旧目录与新中文聚合目录之间的关系，方便玩家、维护者与 AI 系统理解整个资料库结构。

- 当前状态：已整理
- 可信度：`[已确认]`

## 当前采用的结构方式

当前并不是把所有旧目录直接删掉重建，而是采用：

- 旧目录继续保存核心内容
- 新中文目录提供更直观的入口与分类聚合

这样做的好处是：
- 不破坏原有内容积累
- 不会把已有链接与路径一下子打乱
- 可以逐步重构，而不是一次性大搬家

## 为什么不直接只留新目录

- `[已确认]` 因为旧目录下已经有大量具体内容和专题文章。
- `[已确认]` 现阶段更合理的做法是“先让新中文目录成为好入口”，再决定后续是否逐步迁移实体文件。
- `[高可信推断]` 对网页端来说，这种“聚合页 + 原内容页”的方式也更稳定，利于后续做导航与路由。

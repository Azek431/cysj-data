# docs 目录分类对照表

一句话摘要：这份文档用来说明当前 `docs/` 中历史英文目录口径与当前中文聚合目录之间的关系，方便玩家、维护者与 AI 系统理解整个资料库结构。

- 当前状态：已整理
- 可信度：`[已确认]`

## 当前目录结构说明

当前 `docs/` 已经采用中文聚合目录作为主要入口：

- `docs/总索引与导航`
- `docs/教程资料`
- `docs/脚本系统`
- `docs/引擎更新`
- `docs/社区分析`
- `docs/OCR资料`
- `docs/元信息`
- `docs/维护与报告`
- `docs/项目设计`
- `docs/核心研究`

下列英文目录名仅作为历史迁移口径说明，用于理解旧文档中的路径来源；它们不是当前工作区里的真实目录。新链接应优先使用当前中文目录。

## 历史目录口径与新分类的对应关系

### 历史口径：tutorials
主要对应：
- `docs/总索引与导航`
- `docs/教程资料`
- `docs/核心研究`

- 视频学习与入门路线类内容

### 历史口径：scripts

## 为什么保留这份对照表

- `[已确认]` 当前大量正文和索引已迁移为中文路径，但历史资料中仍可能出现英文目录名。
- `[已确认]` 这份表用于解释旧路径含义，避免维护者误以为 tutorials、scripts 等历史口径仍是当前主入口。
- `[高可信推断]` 对网页端来说，保留“历史口径 → 新中文目录”的对照，有利于后续做重定向、导航与链接修复。

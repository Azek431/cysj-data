# 创游世界文档站 UI 重构方案

## 设计目标

将 cysj-data（创游世界文档站）从现有的"装饰性丰富"风格转型为**现代极简风格**的知识库 UI。

核心原则：
- 内容优先，装饰次之
- 克制配色，精致排版
- 干净利落，不留多余元素
- 暗色模式第一（不是浅色模式的附属品）

---

## 二、CSS 架构重构

### 2.1 文件精简

从 9 个文件精简为 5 个：

| 文件 | 职责 | 变更 |
|------|------|------|
| `tokens.css` | 设计令牌 | 全新重写 |
| `typography.css` | 全局排版 | 调整字号/行高/字重 |
| `components.css` | 代码块、表格、引用块 | 去除阴影，改用边框 |
| `layout.css` | 导航栏、侧边栏、分页 | 重新设计 |
| `custom.css` | 自定义组件样式 | 全新重写 |

**移除的文件**：
- `cysj-home.css` → 合并到 `layout.css`（首页区块作为布局的一部分）
- `cysj-animations.css` → **完全移除**（粒子动画、渐变流光、背景呼吸全部去掉）
- `cysj-performance.css` → 合并到 `tokens.css`（性能优化只需要 `will-change` 和 `contain`）
- `cysj-responsive.css` → 合并到 `layout.css`（响应式断点本身就是布局的一部分）

### 2.2 index.ts 加载顺序

```typescript
// 1. 设计令牌（零运行时开销）
import "./styles/tokens.css";

// 2. 排版（首屏必需）
import "./styles/typography.css";

// 3. 组件（首屏必需）
import "./styles/components.css";

// 4. 布局 + 首页 + 响应式（首屏必需）
import "./styles/layout.css";

// 5. 自定义组件（首屏必需）
import "./styles/custom.css";
```

从 9 个文件减少到 5 个，减少约 44% 的 CSS 加载量。

## 三、首页重构

### 3.1 Hero 区域

**现状**：大标题 + 渐变流光 + 粒子背景 + 三个按钮

**新设计**：

```
┌─────────────────────────────────────────────────┐
│                                                  │
│   Azek创游世界文档                               │
│   （更大的标题，更粗的字重）                       │
│                                                  │
│   创游世界脚本、组件、UI 与项目设计知识库          │
│   （更短的副标题，灰色）                           │
│                                                  │
│   [开始阅读] [新手路线] [GitHub]                  │
│   （扁平按钮，无边框无阴影，hover 时微妙变化）       │
│                                                  │
└─────────────────────────────────────────────────┘
```

- 移除粒子动画（HomeParticles.vue 删除）
- 移除渐变流光效果
- 标题字号从 `clamp(2.8rem, ...)` 改为 `clamp(2.4rem, 5vw, 3.2rem)`
- 副标题限制最大宽度 600px，居中对齐
- 按钮组：主按钮（品牌色实心）+ 次要按钮（边框色 + 透明背景）
- 背景保持纯白（浅色）/ 纯黑（深色），不加任何装饰

### 3.2 Feature 卡片区域

**现状**：6 张卡片，2 行 3 列，带 emoji 图标、hover 上浮 + 阴影

**新设计**：

```
┌──────────────┬──────────────┬──────────────┐
│ 🧭 新手路线  │ 🧩 脚本系统  │ 🎨 UI 设计   │
│ 描述...      │ 描述...      │ 描述...      │
│ [查看路线 →] │ [查看脚本 →] │ [查看 UI →]  │
├──────────────┼──────────────┼──────────────┤
│ 🏗️ 项目设计  │ 🔎 OCR 资料  │ 🛠️ 维护规范  │
│ 描述...      │ 描述...      │ 描述...      │
│ [查看设计 →] │ [查看 OCR →] │ [查看维护 →] │
└──────────────┴──────────────┴──────────────┘
```

- 从 3 列改为 3 列，但卡片更紧凑
- 移除 hover 上浮 + 阴影增强
- 改用：hover 时边框变色（从灰色 → 品牌色）
- Emoji 图标改为纯 CSS 圆形背景 + emoji
- 卡片尺寸缩小，间距缩小
- 链接文字从"查看 XX 资料"改为"→"箭头符号

### 3.3 首页其余内容

保留但优化：
- "这个资料库适合谁？" → 改为更简洁的列表
- "推荐阅读路径" → 改为手风琴折叠面板（默认折叠）
- "资料可信度说明" → 改为简洁表格
- "快速入口" → 改为一行标签链接

### 4.1 顶部导航栏

**现状**：64px 高，logo + 导航链接 + 搜索 + 暗色切换

**新设计**：

- 高度降至 **56px**
- 背景：浅色 `#fafafa` / 深色 `#0a0a0a`
- 边框：底部 1px 细线 `#e5e5e5` / `#222`
- Logo 和文字间距缩小
- 下拉菜单：无阴影，仅靠边框区分，字号 14px
- 搜索框：扁平化，无边框，hover 时显示边框

### 4.2 侧边栏

**现状**：256px 宽，活跃项左侧渐变竖条

**新设计**：

- 宽度缩至 **240px**
- 移除渐变竖条指示器
- 改为：活跃项文字变品牌色，左侧 2px 蓝色实线
- 分组标题：更小的字号（11px），全大写，字间距加宽
- 折叠动画：更短（120ms）

## 七、暗色模式升级

### 7.1 核心理念

暗色模式不再是浅色模式的"反转"，而是**一等公民**。

**关键变化**：

1. **背景不用纯黑**：使用 `#0a0a0a`（接近纯黑但有温度）
2. **卡片用深灰边框区分**：不再依赖阴影
3. **文本对比度优化**：正文 `#ededed`（92% 不透明度），次要 `#aaaaaa`（67%）
4. **品牌色调整**：从亮蓝 `#60a5fa` 改为沉稳蓝 `#4d9de6`，减少刺眼感
5. **代码块深色背景**：`#141414`，与页面背景有明显区分
6. **滚动条**：自定义深色滚动条，更细更低调

### 7.2 暗色模式切换

- 默认跟随系统（`prefers-color-scheme`）
- 手动切换按钮保留
- 切换时有 120ms 的微妙过渡（背景色平滑变化）

## 十、预期效果

**重构前**：装饰丰富的知识库，粒子动画、渐变流光、多层阴影、三色品牌渐变
**重构后**：现代极简的知识库，干净排版、克制配色、无边框阴影、专注内容

类比参考风格：类似 Linear.app 的简洁感 + Obsidian 的专注阅读体验 + Vercel 文档的专业感，但完全从零设计，不复制任何特定网站。

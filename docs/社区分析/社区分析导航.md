## 内容说明

### 关于社区分析文档

本分类下的文档主要来源于：

1. **用户反馈收集**：从论坛、社群收集的用户常见问题和解决方案
2. **经验归纳总结**：基于多个项目经验的通用规律总结
3. **待验证问题整理**：尚未得到官方确认的推测和观察
4. **社区动态追踪**：版本更新、用户增长、功能反馈等

### 证据等级说明

| 证据等级 | 说明 | 使用要求 |
|----------|------|----------|
| E4 | 社区经验/推测 | 必须标注「待验证」或「社区观察」 |
| 待验证 | 无法确认 | 截图不清、原文缺失、推测等 |

> 详细信息请参考：[OCR 证据使用规范](/OCR资料/OCR%20证据使用规范)

## 待验证问题清单

### 用户反馈类

- 用户报告的常见问题及其解决方案的有效性
- 社区推荐的最佳实践是否适合所有场景
- 不同版本引擎的行为差异

### 技术推测类

- 某些 API 的内部实现原理
- 组件能力边界和性能限制
- 数据同步机制的具体细节

### 版本相关

- 旧版本功能的兼容性变化
- 新功能的稳定性和适用场景
- 引擎更新的具体影响范围

# 知识标签体系总表

[[toc]]

## 1. 文档目的

本表用于给 `创游世界资料汇总` 知识库建立较统一的标签体系，方便后续：

- 全局搜索
- 文档聚类
- AI/RAG 切块检索
- 同主题自动归档
- 后续批量补索引

原则上，标签不求一次性极多，而求：
- 命名稳定
- 粒度适中
- 能长期复用
- 能覆盖主要研究方向

## 9. 推荐打标签规则

### 9.1 单篇文档标签数量建议
- 主标签：1~2 个
- 次标签：3~6 个
- 不建议堆太多近义词

### 9.2 命名优先级
优先使用已经在知识库中稳定出现的表达，例如：
- 用“系统属性”而不是“全局属性”混写
- 用“地图属性”而不是“场景属性”混写
- 用“当前UI”而不是多个自定义说法混写

### 9.3 视频文档标签
视频文档建议同时打：
- 内容标签
- 难度标签
- 实战标签

例如：
- 教程 / 脚本 / UI / 背包系统 / 入门 / 可复现

---

## 10. 后续维护建议

1. 新增文档时优先从本表选标签，不轻易新增同义词
2. 若确实需要新标签，应先判断是否能并入现有标签体系
3. 后续可为高价值文档补“标签汇总区块”，提升检索一致性

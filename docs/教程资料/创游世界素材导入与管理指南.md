# 创游世界素材导入与管理指南

[[toc]]

本文详细介绍创游世界编辑器中素材的导入方式、分类方法、整理技巧和文件夹管理策略，帮助你高效管理项目资源，避免素材混乱导致的开发效率下降。

## 核心结论

1. **素材分类要提前规划**：一开始就把素材分好类，比后期整理要高效得多
2. **命名规范很重要**：统一命名风格可以让脚本查找更方便，减少调试时间
3. **善用文件夹**：大量素材时，文件夹是保持秩序的关键
4. **定期整理**：开发过程中定期清理无用素材，保持项目整洁

## 素材导入方式

### 方式一：直接从相册导入

最简单的方式，适合快速添加素材：

1. 打开素材区
2. 点击分类旁边的蓝色 `+` 按钮
3. 选择「从相册选择」
4. 选择图片

**适用场景**：临时添加少量素材、快速测试

### 方式二：拍照导入

适合即时创建简单素材：

1. 点击分类旁边的 `+` 按钮
2. 选择「拍照」
3. 拍摄照片
4. 自动导入为素材

**适用场景**：创建简单图标、快速原型

### 方式三：文件管理器导入

适合批量导入大量素材：

1. 准备好图片文件（支持 PNG、JPG 等格式）
2. 打开文件管理器
3. 进入创游世界项目文件夹
4. 将图片复制到对应目录
5. 在编辑器中刷新素材列表

**适用场景**：批量导入、导入其他来源的素材包

## 素材分类系统

### 默认分类说明

| 分类 | 用途 | 典型内容 |
|------|------|----------|
| 地块 | 地面、墙面等静态背景 | 草地、土地、石头墙 |
| 装饰 | 环境点缀 | 树木、花草、石头 |
| 角色 | 可控制或NPC | 玩家角色、怪物、NPC |
| 装置 | 功能性物体 | 机关、门、箱子 |
| 道具 | 可拾取物品 | 金币、药水、钥匙 |
| 武器 | 角色装备 | 剑、弓、法杖 |
| UI素材 | 界面资源 | 按钮图标、背景图 |
| 背景 | 背景图片 | 天空、海景 |

### 自定义分类

如果默认分类不够用，可以：

1. 长按分类名称
2. 选择「重命名」
3. 输入自定义名称

**建议**：根据项目需求自定义，避免分类过多导致混乱

## 文件夹管理技巧

### 创建文件夹

1. 在素材区空白处长按
2. 选择「新建文件夹」
3. 输入文件夹名称
4. 将素材拖入文件夹

### 文件夹命名建议

```
📁 角色
  ├── 📁 玩家
  ├── 📁 怪物
  └── 📁 NPC

📁 场景
  ├── 📁 室内
  └── 📁 室外

📁 道具
  ├── 📁 消耗品
  ├── 📁 装备
  └── 📁 任务物品

📁 UI
  ├── 📁 图标
  ├── 📁 背景
  └── 📁 按钮
```

### 文件夹使用原则

| 原则 | 说明 |
|------|------|
| 层级不过深 | 建议最多 2-3 层 |
| 名副其实 | 文件夹名称要能反映内容 |
| 统一风格 | 命名风格要统一 |
| 定期整理 | 及时清理空文件夹 |

## 素材命名规范

### 为什么要规范命名

好的命名可以：
- 快速找到需要的素材
- 减少脚本编写时的错误
- 便于团队协作
- 后期维护更轻松

### 命名建议

#### 风格一：下划线分隔

```
player_walk_01.png      // 玩家行走图1
player_walk_02.png      // 玩家行走图2
monster_slime_red.png   // 红色史莱姆怪物
coin_gold_100.png      // 100金币
```

#### 风格二：驼峰命名

```
playerWalk01.png
playerWalk02.png
monsterSlimeRed.png
coinGold100.png
```

#### 风格三：中文拼音

```
玩家_走路_01.png
玩家_走路_02.png
怪物_史莱姆_红色.png
金币_100.png
```

### 命名要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 主体 | 素材是什么 | player, coin, door |
| 类型 | 角色/道具/场景 | character, item, prop |
| 状态 | 动作或状态 | walk, idle, open |
| 序号 | 用于区分多个同类素材 | 01, 02, 03 |
| 规格 | 尺寸或品质 | large, small |

## 素材库高效使用策略

### 策略一：建立项目素材库

在项目初期就规划好素材结构：

```
项目文件夹
├── 角色素材/
├── 场景素材/
├── 道具素材/
├── UI素材/
├── 音效/
└── 背景音乐/
```

### 策略二：使用预设模板

创建项目时可以：

1. 先创建常用的文件夹结构
2. 预先放置一些占位素材
3. 后续替换为正式素材

### 策略三：善用搜索

当素材很多时：

1. 使用搜索框输入关键词
2. 支持按名称筛选
3. 快速定位素材

### 策略四：批量操作

1. 选中多个素材
2. 批量移动到文件夹
3. 批量重命名

## 素材使用技巧

### 快速拖入地图

1. 在素材区找到素材
2. 直接拖入地图
3. 素材自动变成物体

### 快速复制

1. 在地图上选中物体
2. 按住复制（Ctrl+C 或拖拽复制）
3. 放置到新位置

### 批量选择同素材物体

1. 右键点击素材
2. 选择「选中所有使用此素材的物体」
3. 批量修改或删除

## 常见问题与解决方案

### Q1：导入的素材显示模糊？

**A**：
1. 检查图片分辨率是否足够
2. 避免使用过度压缩的图片
3. 建议使用 PNG 格式保持清晰度
4. 检查缩放设置是否正确

### Q2：素材无法导入？

**A**：
1. 检查文件格式是否支持
2. 检查文件名是否有特殊字符
3. 检查图片是否损坏
4. 尝试重新压缩图片

### Q3：素材太多找起来很慢？

**A**：
1. 使用文件夹分类
2. 使用搜索功能
3. 定期整理，删除无用素材
4. 为常用素材添加收藏

### Q4：素材改名后地图里的物体没变？

**A**：
1. 素材改名不影响已放置的物体
2. 物体使用的是素材的引用
3. 需要手动更新物体

### Q5：如何快速替换同类型素材？

**A**：
1. 使用「替换素材」功能
2. 选中所有需要替换的物体
3. 批量替换为新素材

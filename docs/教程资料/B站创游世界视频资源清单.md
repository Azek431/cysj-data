## 9. 研究结论

从公开搜索结果看，B 站上的创游世界教程大致分成 5 个稳定方向：

1. **新手引导类**：教你开始界面、基础概念、商品购买、少走弯路。
2. **脚本基础类**：变量、移动、闪避、换弹、随机、签到、抽奖。
3. **UI 系统类**：基础 UI、位置适配、格子 UI、自定义 UI。
4. **组件与封装类**：自定义组件、角色组件、Buff组件、触摸板等。
5. **实战功能类**：血条、货币、背包、翻滚、滑铲、回血、演出效果。

这说明创游世界社区的学习核心，已经从“怎么拖素材”逐渐转向：
- 用脚本做功能
- 用 UI 做反馈
- 用组件做复用
- 用系统化结构做更完整的游戏

### 10.2 直达链接字段如何理解

由于当前公开搜索结果中，部分 B 站结果会把视频页地址截断显示为：
- `https://www.bilibili.com/video/B...`
- `m.bilibili.com/video/BV1...`

这说明：
- 已能确认该条目存在独立视频页；
- 但搜索结果页未必把完整 BV 号完全展开；
- 因此本清单同时保留 `直达链接` 与 `检索链接` 两层导航。

实际使用建议：
1. 优先点 `直达链接`；
2. 如果直达链接不完整或失效，就点 `检索链接`；
3. 进入 B 站后，再把完整 BV 号回填到知识库。

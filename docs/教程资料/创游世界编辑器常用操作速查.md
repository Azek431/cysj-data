## 1. 素材管理速查

### 1.1 素材导入与创建

| 操作 | 方法 |
|------|------|
| 导入图片素材 | 素材区右键 → 导入 → 选择图片文件 |
| 创建空白素材 | 素材区右键 → 新建素材 |
| 创建文件夹 | 素材区右键 → 新建文件夹 |
| 复制素材 | 右键素材 → 复制 |

### 1.2 素材整理

| 操作 | 方法 |
|------|------|
| 重命名素材 | 右键 → 重命名 / 双击名称 |
| 移动到文件夹 | 拖拽素材到目标文件夹 |
| 删除素材 | 右键 → 删除 / 选中后按Delete |
| 复制素材 | 右键 → 复制 |

### 1.3 素材配置

| 操作 | 方法 |
|------|------|
| 编辑素材属性 | 双击素材 → 在属性面板修改 |
| 设置素材尺寸 | 在属性面板调整宽高 |
| 设置锚点 | 在属性面板设置中心点 |

## 2. 地图编辑速查

### 2.1 物体操作

| 操作 | 方法 |
|------|------|
| 放置物体 | 从素材区拖拽到地图 / 双击素材 |
| 选择物体 | 左键点击 |
| 多选 | Ctrl+左键点选 / 框选 |
| 取消选择 | 点击空白处 / Esc |
| 移动物体 | 拖拽 / 方向键微调 |
| 删除物体 | Delete键 / 右键 → 删除 |

### 2.2 物体变换

| 操作 | 方法 |
|------|------|
| 旋转物体 | 拖拽旋转手柄 / 右键菜单设置角度 |
| 缩放物体 | 拖拽缩放手柄 / 右键菜单设置大小 |
| 翻转物体 | 右键菜单 → 水平翻转/垂直翻转 |
| 置于顶层 | 右键 → 置于顶层 |
| 置于底层 | 右键 → 置于底层 |

### 2.3 地图视图

| 操作 | 方法 |
|------|------|
| 平移视图 | 鼠标中键拖拽 / Ctrl+鼠标左键拖拽 |
| 缩放视图 | 鼠标滚轮 |
| 适应窗口 | 双击滚轮 / Ctrl+0 |
| 网格显示 | 视图菜单 → 显示网格 |

### 2.4 玩家角色

| 操作 | 方法 |
|------|------|
| 添加玩家 | 切换到角色分类 → 点击右下角「添加玩家」 |
| 移动玩家 | 拖拽玩家位置 |
| 删除玩家 | 选中玩家 → Delete |

## 3. 组件速查

### 3.1 添加组件

1. 在地图中选中物体
2. 在属性面板中找到「组件」区域
3. 点击「添加组件」
4. 从分类列表中选择需要的组件
5. 在下方配置组件参数

### 3.2 常用组件速查

| 需求 | 需要组件 |
|------|----------|
| 让角色能动 | 物理 + 角色 |
| 让物体可交互 | 可互动 |
| 让物体成为障碍 | 阻挡通行 |
| 让物体显示UI | 物体UI |
| 让物体有血量 | 生命 |
| 让物体造成伤害 | 伤害 |
| 让物体拿武器 | 武器槽 |
| 让物体发射子弹 | 子弹 |
| 让物体成为机关 | 机关 |
| 让物体成为门 | 机关门 |
| 让物体成为开关 | 开关 |

### 3.3 移除/禁用组件

| 操作 | 方法 |
|------|------|
| 移除组件 | 在组件列表中找到 → 点击删除按钮 |
| 禁用组件 | 在组件列表中找到 → 取消勾选 |

## 4. 脚本速查

### 4.1 打开脚本编辑器

| 方法 | 说明 |
|------|------|
| 双击物体 | 在地图中双击物体 → 打开脚本编辑器 |
| 属性面板 | 选中物体 → 点击属性面板中的「编辑脚本」 |
| 快速编辑 | 选中物体 → 按E键 |

### 4.2 触发时机选择

| 触发时机 | 适用场景 |
|----------|----------|
| 当被创建时 | 初始化设置 |
| 当被点击时 | 点击交互 |
| 当接近时 | 靠近触发 |
| 当受到伤害时 | 受伤逻辑 |
| 当死亡时 | 死亡处理 |
| 当收到广播时 | 事件响应 |
| 重复执行直到 | 持续检测 |

### 4.3 常用积木块

#### 控制类

| 积木块 | 用途 |
|--------|------|
| 如果...那么 | 条件判断 |
| 如果...那么...否则 | 分支判断 |
| 重复执行直到 | 循环执行 |
| 等待 | 暂停等待 |
| 停止当前脚本 | 结束执行 |

#### 数据类

| 积木块 | 用途 |
|--------|------|
| 新建局部变量 为 | 创建临时变量 |
| 设置变量 | 修改变量值 |
| 获取变量 | 读取变量值 |
| 设置自身属性 | 修改自身状态 |
| 设置当前地图属性 | 修改地图级状态 |
| 设置系统属性 | 修改全局状态 |

#### 动作类

| 积木块 | 用途 |
|--------|------|
| 发送广播 | 发送事件通知 |
| 向当前UI发广播 | 通知当前UI |
| 播放动画 | 播放对象动画 |
| 销毁自身 | 销毁当前物体 |
| 移动到 | 移动物体位置 |

### 4.4 保存与测试

| 操作 | 方法 |
|------|------|
| 保存脚本 | 脚本编辑器底部 → 点击「保存」 |
| 试玩 | 脚本编辑器底部 → 点击「试玩」 |
| 停止试玩 | 试玩窗口 → 点击停止按钮 |

## 5. 调试速查

### 5.1 常见问题检查

| 问题 | 检查项 |
|------|--------|
| 角色走不动 | 是否挂了「物理」+「角色」组件 |
| 不能交互 | 是否挂了「可互动物体」组件 |
| 物体没有功能 | 是否挂了需要的组件 |
| 脚本不执行 | 是否在正确的触发时机下 |
| 修改没生效 | 是否保存了脚本 |
| 素材改了没变 | 是否应用了「应用到原素材」 |

### 5.2 调试技巧

| 技巧 | 方法 |
|------|------|
| 查看碰撞盒 | 试玩时打开碰撞盒显示 |
| 输出变量值 | 使用「显示文字」或广播打印 |
| 逐行Debug | 使用逐行执行功能 |
| 断点测试 | 在关键位置添加临时广播测试 |

## 6. UI速查

### 6.1 三种UI类型

| 类型 | 调用方式 |
|------|----------|
| 地图UI | 地图UI设置 → 切换UI |
| 操作UI | 操作UI设置 → 切换UI |
| 物体UI | 需要先挂载「物体UI」组件 |

### 6.2 UI切换

| 操作 | 方法 |
|------|------|
| 打开UI | 使用对应UI类型的切换指令 |
| 关闭UI | 使用关闭UI指令 |
| 物体UI | 先给物体挂载「物体UI」组件 |

### 6.3 UI与数据

> **原则**：UI只负责显示和接收输入，真值放在地图层或系统层。

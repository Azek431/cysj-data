创游世界三种 UI 类型的快速对比表，帮助快速理解地图 UI、操作 UI、物体 UI 的区别、使用场景和切换方法。

## 三种UI类型对比

| 特性 | 地图 UI | 操作 UI | 物体 UI |
|------|--------|---------|----------|
| **显示位置** | 覆盖在地图上 | 覆盖在地图上 | 挂载在物体上 |
| **典型用途** | HUD、提示框 | 菜单、面板 | 血条、NPC 对话 |
| **控制方式** | 脚本显示/隐藏 | UI 切换积木 | 物体 UI 组件 |
| **生命周期** | 随地图存在 | 切换显示 | 随物体存在 |
| **通信方式** | 脚本控制 | 按钮交互 | 组件配置 |

## 地图UI

### Q：什么是地图 UI？

**A**：显示在地图场景上的 UI 元素，如 HUD、提示框、通关提示。

---

### Q：地图 UI 怎么用？

**A**：
1. 在素材区创建「UI」类型素材
2. 拖入地图
3. 在脚本中控制显示/隐藏

```
当开始时
  隐藏 UI "提示面板"
结束

当满足条件时
  显示 UI "提示面板"（过渡动画：弹出）
结束
```

---

### Q：地图 UI 适合做什么？

**A**：
- 任务提示
- 通关/失败提示
- 临时提示文字
- 倒计时显示
- 分数/金币 HUD

---

### Q：地图 UI 的特点？


| 特点 | 说明 |
|------|------|
| 脚本控制 | 通过积木控制显示/隐藏 |
| 位置固定 | 通常固定在屏幕某个位置 |
| 生命周期 | 随地图存在 |
| 切换简单 | 直接显示/隐藏即可 |


---

## 操作UI

### Q：什么是操作 UI？

**A**：覆盖在地图上的操作界面，如开始菜单、设置面板、背包界面。

---

### Q：操作 UI 怎么切换？

**A**：使用「切换 UI」积木。
```
当点击按钮 "开始游戏" 时
  切换 UI "游戏界面"（过渡动画：淡入）
  隐藏 UI "开始菜单"
结束

当点击按钮 "背包" 时
  切换 UI "背包界面"（过渡动画：弹出）
结束
```

---

### Q：操作 UI 适合做什么？

**A**：
- 开始菜单
- 设置面板
- 背包界面
- 商店界面
- 暂停菜单
- 任务追踪面板


---

### Q：操作 UI 的特点？

| 特点 | 说明 |
|------|------|
| 整体切换 | 整块界面切换 |
| 过渡动画 | 支持淡入、弹出等效果 |
| 按钮交互 | 通过按钮触发交互 |
| 常驻隐藏 | 默认隐藏，通过切换显示 |

---

### Q：操作 UI 找不到怎么办？


**A**：确认你要用的是「操作 UI」类型，然后去「操作 UI 设置」里找切换入口。

---

## 物体UI

### Q：什么是物体 UI？

**A**：挂载在特定物体上的 UI 组件，如头顶血条、NPC 对话气泡。

---

### Q：物体 UI 怎么用？


**A**：
1. 给物体添加「物体 UI 组件」
2. 配置绑定的 UI 资源
3. 设置显示位置和偏移
4. 脚本中控制显示/隐藏

```
当受伤时
  显示物体 UI "血条"
结束

当死亡时
  隐藏物体 UI "血条"
结束
```

---

### Q：物体 UI 适合做什么？

**A**：
- 头顶血条
- NPC 对话气泡
- 交互提示
- 伤害飘字
- 物品名称标签

---

### Q：物体 UI 的特点？

| 特点 | 说明 |
|------|------|
| 位置跟随 | 跟随物体移动 |
| 组件绑定 | 需要物体 UI 组件 |
| 生命周期 | 随物体存在 |
| 配置参数 | 显示偏移、位置等 |

---

## 切换方法对比

| UI 类型 | 切换方法 | 控制脚本位置 |
|--------|----------|-------------|
| 地图 UI | `显示 UI` / `隐藏 UI` | 任意物体脚本 |
| 操作 UI | `切换 UI` 积木 | UI 自身脚本 |
| 物体 UI | `显示物体 UI` / `隐藏物体 UI` | 物体自身脚本 |

## 数据流模式

### 地图 UI 数据流

```
地图逻辑 → 修改真值 → 发送广播 → 地图 UI 响应 → 更新显示
```

### 操作 UI 数据流

```
按钮点击 → 发送广播 → 地图处理 → 发送广播 → UI 刷新
```

### 物体 UI 数据流


```
战斗逻辑 → 修改生命值 → 物体 UI 自动更新
     或
触发时机 → 显示/隐藏 → 物体 UI 响应
```

## 常见问题类

### Q：为什么切换 UI 时找不到做好的 UI？


**A**：创游有三种 UI，每种 UI 的切换入口不同：
- 地图 UI → 脚本控制
- 操作 UI → 操作 UI 设置
- 物体 UI → 需要先给物体挂「物体 UI 组件」

**解决方法**：先确认你要找的是哪种 UI。


---

### Q：为什么有两个 UI 重叠关不掉？


**A**：默认操作 UI 仍在自动生效。

**解决方法**：进入「操作 UI 设置」，找到「默认操作 UI」，关闭或改空默认项。

---

### Q：UI 状态在切地图后会错乱？

**A**：UI 层的临时状态不等于项目真值层。


**正确做法**：
- 真值放在地图层或系统层
- UI 只负责显示和接收输入
- 切地图时，真值会保留；临时 UI 状态会重置

---

### Q：联机时 UI 为什么会很卡？

**A**：旧版本每个玩家设备会模拟所有玩家的 UI 逻辑。

**解决方法**：
- 更新到 4.52.54+ 版本
- 使用「当前 UI」写法
- UI 只发一次广播，不要连续发多次

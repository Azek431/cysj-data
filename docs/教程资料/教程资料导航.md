## 核心概念速查

| 概念 | 说明 |
|------|------|
| **素材** | 放在地图前的模板资源，包含贴图和可挂载的组件配置 |
| **组件** | 赋予物体"能力"的模块，决定物体"能做什么" |
| **脚本** | 用积木块拼装的行为逻辑，决定对象在特定时机下做什么 |
| **广播** | 消息发布-订阅机制，用于对象间的解耦通信 |
| **触发时机** | 脚本在"什么情况下"被执行 |
| **变量作用域** | 局部变量 → 自身属性 → 地图属性 → 系统属性 |

## 常见问题快速链接

- 角色走不动？→ 检查物理组件和角色组件是否挂载
- UI 切换找不到？→ 确认是地图UI、操作UI还是物体UI
- 广播没效果？→ 检查广播名称是否完全一致
- 变量值丢失？→ 确认变量放在了正确的位置

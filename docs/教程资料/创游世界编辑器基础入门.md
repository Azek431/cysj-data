# 创游世界编辑器基础入门

## 一句话摘要

本文档介绍创游世界游戏编辑器的基础操作，帮助新手快速理解编辑器界面、掌握素材管理、组件挂载、脚本编写和 UI 创建五大核心功能。

## 适合谁阅读

- 刚下载创游世界不知道怎么开始的新手
- 想系统了解编辑器基本操作的玩家

## 编辑器整体界面

创游世界编辑器采用可视化拖拽式设计，不需要编写代码。整个界面可以大致分为以下几个区域：

| 区域 | 主要功能 |
|------|---------|
| 素材区 | 管理游戏中使用的图片、音频等资源 |
| 编辑区 | 放置和编辑地图中的物体 |
| 组件区 | 为物体挂载能力组件 |
| 脚本区 | 编写物体的行为逻辑 |
| UI 区 | 创建游戏界面 |

## 素材管理

### 导入素材

1. 点击素材区右上角的 **+** 按钮
2. 选择导入方式（拍照/相册/文件）
3. 选择要导入的图片或音频
4. 等待素材加载完成

### 素材分类

- 在素材区可以创建文件夹进行分类
- 右键素材 → 新建文件夹
- 把同类素材拖入同一文件夹
- 方便大型项目的资源管理

### 常见素材类型

| 类型 | 用途 |
|------|------|
| 图片 | 角色、道具、装饰、背景 |
| BGM | 背景音乐，无时长限制 |
| 音效 | 短促反馈音（4.54.0后最长30秒） |

## 组件系统

### 什么是组件

组件是给物体赋予「能力」的模块：
- **贴图**决定物体「看起来像什么」
- **组件**决定物体「能做什么」

不给物体挂载组件，它就只是一个静态图片。

### 组件分类

创游世界的组件分为六大类：

| 分类 | 包含组件 | 主要功能 |
|------|----------|----------|
| 通用 | 物理、阻挡通行、物体UI | 基础交互能力 |
| 战斗 | 生命、伤害、武器槽、子弹 | 战斗相关能力 |
| 装置 | 机关、机关门、机关地板 | 机关设计 |
| 显示 | 粒子特效、动效 | 视觉效果 |
| 交互 | 移动摇杆、技能摇杆、互动按钮 | 用户输入 |
| 自定义 | 自定义组件 | 自定义功能 |

### 如何挂载组件

1. 选中地图中的物体
2. 点击「添加组件」按钮
3. 在组件列表中选择需要的组件
4. 配置组件参数

### 常见组件组合

| 需求 | 需要挂载的组件 |
|------|---------------|
| 让角色能移动 | 角色组件 + 物理组件 |
| 让物体能被点击 | 可互动物体组件 |
| 让物体有血条 | 生命组件 + 物体UI组件 |
| 让角色能拿武器 | 角色组件 + 武器槽组件 |

## 脚本系统

### 什么是脚本

脚本是用积木块拼装的行为逻辑，决定物体在「什么时机」做「什么操作」。

```
触发时机 + 积木块组合 = 脚本
```

### 如何打开脚本编辑器

1. 选中地图中的物体
2. 点击「写脚本」或「编辑脚本」
3. 进入脚本编辑器界面

### 常用触发时机

| 触发时机 | 适用场景 |
|----------|----------|
| 当被创建时 | 初始化设置 |
| 当被点击时 | 交互反馈 |
| 当收到广播时 | 接收消息 |
| 当接近时 | 距离触发 |
| 当受到伤害时 | 战斗逻辑 |
| 重复执行直到 | 循环逻辑 |

### 变量作用域

| 层级 | 名称 | 说明 |
|------|------|------|
| 局部变量 | 临时数据 | 脚本执行完就消失 |
| 自身属性 | 组件数据 | 属于当前物体 |
| 地图属性 | 场景数据 | 同地图共享 |
| 系统属性 | 全局数据 | 整个游戏通用 |

## UI 系统

### 三种 UI 类型

| 类型 | 说明 | 使用场景 |
|------|------|----------|
| 地图UI | 跟地图或场景级逻辑联动 | 剧情对话框、任务面板 |
| 操作UI | 玩家操作入口 | 虚拟摇杆、技能按钮 |
| 物体UI | 绑定到特定物体 | 物体交互界面 |

### 创建 UI 面板

1. 进入 UI 编辑界面
2. 添加需要的 UI 元素（按钮、图片、文字等）
3. 为 UI 元素配置属性
4. 在脚本中通过广播与 UI 交互

### UI 设计原则

- **真值与显示分离**：UI 负责显示和接收输入，真值放在地图层或系统层
- **避免在 UI 中直接修改全局状态**：推荐通过广播通知地图处理
- **联机环境下减少多次写入**：每个玩家只运行自己的 UI 逻辑

## 快速开始练习

### 第一个练习：会移动的角色

1. 添加一个角色素材到地图
2. 挂载「角色组件」
3. 挂载「物理组件」
4. 点击试玩，角色就可以移动了

### 第二个练习：可交互的物体

1. 添加一个素材到地图
2. 挂载「可互动物体」组件
3. 写脚本：当被点击时，播放声音或显示提示
4. 点击试玩，接近时会出现互动按钮

### 第三个练习：简单的 UI 面板

1. 创建一个地图UI
2. 添加一个按钮
3. 写脚本：当按钮被点击时，发送广播
4. 在地图脚本中监听广播并执行相应操作

## 常见问题

### Q：为什么角色走不动？

**可能原因：**
1. 缺少「角色组件」或「物理组件」
2. 地块有「阻挡通行」属性
3. 碰撞盒设置过大

**解决方法：**
- 选中玩家对象 → 添加「角色组件」+「物理组件」
- 检查地块设置，移除阻挡属性
- 调整碰撞盒大小

### Q：改了素材，地图里的物体没变化？

**原因：** 地图里的物体是实例，不会自动跟随素材更新。

**解决方法：**
- 方案1：删除旧物体，用新素材重新摆
- 方案2：选中地图物体 → 「应用到原素材」同步配置

### Q：广播发出去没效果？

**检查清单：**
1. 广播名称是否完全一致（注意大小写）
2. 监听脚本是否在「当收到广播时」触发时机下
3. 监听者在广播发送时是否仍存在
4. 广播发送时机是否在监听者初始化之后

### Q：脚本不执行怎么办？

**检查清单：**
1. 是否选择了正确的触发时机
2. 脚本名称是否写错
3. 积木块组合是否有语法错误
4. 执行时机是否在监听者初始化之后

### Q：互动按钮不显示？

**原因：** 互动按钮默认隐藏，只有玩家接近「可互动物体」时才显示。

**解决方法：**
- 确认物体已挂载「可互动物体」组件
- 如果想做常驻按钮，使用普通「按钮」组件

### Q：UI 切换找不到？

**原因：** 创游有三种 UI，每种 UI 的切换入口不同。

| UI 类型 | 切换入口位置 |
|--------|------------|
| 地图 UI | 地图 UI 设置 |
| 操作 UI | 操作 UI 设置 |
| 物体 UI | 需要先给物体挂「物体 UI 组件」 |

### Q：两个 UI 重叠关不掉？

**原因：** 默认操作 UI 仍在自动生效。

**解决方法：**
1. 进入「操作 UI 设置」
2. 找到「默认操作 UI」
3. 关闭或改空默认项

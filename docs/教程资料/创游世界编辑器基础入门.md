# 创游世界编辑器基础入门

[[toc]]

## 一句话摘要

本文介绍创游世界编辑器的基本结构与入门操作，帮助你从零开始理解界面布局、功能区域、素材管理和地图编辑的核心流程。

## 适合谁阅读

- 刚下载创游世界不知道编辑器怎么用的新手
- 想系统了解编辑器基本操作的创作者
- 需要复习编辑器基础概念的开发者

## 你将学到什么

- 编辑器的基本界面布局
- 素材管理的基本方法
- 地图编辑的核心操作
- 组件挂载的基础概念
- 试玩与保存的工作流程

## 核心结论

1. **编辑器分为素材区和地图区**：左边是素材管理，右边是地图编辑
2. **素材是模板，物体是实例**：素材拖入地图才变成物体
3. **组件决定能力**：不给物体挂组件，就只是静态图片
4. **试玩前记得保存**：保存才能让新加的脚本生效

## 1. 编辑器界面总览

### 1.1 界面布局

创游世界编辑器的界面大致分为以下区域：

| 区域 | 位置 | 主要功能 |
|------|------|----------|
| 菜单栏 | 顶部 | 文件、编辑、视图、运行等操作 |
| 素材区 | 左侧 | 管理所有素材、组件、脚本配置 |
| 地图区 | 右侧中央 | 编辑游戏场景，摆放物体 |
| 属性面板 | 右侧 | 查看和修改选中对象的属性 |
| 工具栏 | 上方 | 常用工具：选择、缩放、旋转等 |
| 预览区 | 底部/右侧 | 游戏预览和调试 |

### 1.2 快速上手三件事

1. **导入素材**：把图片或素材放进编辑器
2. **拖入地图**：把素材从左侧拖到右侧地图区域
3. **挂载组件**：给地图里的物体添加功能组件

## 2. 素材管理

### 2.1 什么是素材

素材是可用于游戏的资源模板，包括：
- **图片素材**：角色、道具、装饰等
- **组件配置**：预设的功能组件组合
- **文件夹**：用于组织和分类素材

### 2.2 素材的基本操作

| 操作 | 说明 |
|------|------|
| 导入素材 | 从本地导入图片作为素材 |
| 创建素材 | 新建空白素材或组件配置 |
| 复制素材 | 复制现有素材 |
| 移动素材 | 在文件夹之间移动素材 |
| 删除素材 | 删除不需要的素材 |
| 重命名素材 | 给素材起有意义的名字 |

### 2.3 素材的分类

| 分类 | 说明 |
|------|------|
| 角色 | 玩家角色、敌人、NPC等 |
| 装饰 | 场景装饰、背景元素 |
| 地块 | 地形、地面、墙壁等 |
| 装置 | 可交互的机关、门、开关等 |
| 道具 | 可拾取或使用的物品 |
| 武器 | 武器、装备等 |

### 2.4 素材与物体的关系

> **重要概念**：素材是模板，物体是实例。

```
素材（模板）
    ↓ 拖入地图
物体（实例）
```

**关键理解**：
- 修改素材模板，不会自动更新地图里已有的物体
- 地图里的物体是独立的实例，有自己的属性和状态
- 可以使用"应用到原素材"把物体配置同步回模板

## 3. 地图编辑

### 3.1 地图基础操作

| 操作 | 说明 |
|------|------|
| 新建地图 | 创建一个新场景 |
| 切换地图 | 在不同地图之间切换 |
| 缩放地图 | 调整地图编辑视图的缩放比例 |
| 平移地图 | 移动地图视图位置 |

### 3.2 物体操作

| 操作 | 说明 |
|------|------|
| 放置物体 | 从素材区拖入地图 |
| 选择物体 | 点击选中地图中的物体 |
| 移动物体 | 拖动调整位置 |
| 旋转物体 | 调整物体的朝向 |
| 缩放物体 | 调整物体的大小 |
| 复制物体 | 复制地图中的物体 |
| 删除物体 | 删除不需要的物体 |
| 层级调整 | 调整物体的前后遮挡关系 |

### 3.3 添加玩家角色

如果地图里没有玩家角色：

1. 切换素材到「角色」分类
2. 点击右下角「添加玩家」
3. 玩家角色会被放置到地图中心

## 4. 组件系统基础

### 4.1 什么是组件

组件是给物体赋予「能力」的模块。

**核心理解**：
- 贴图决定「看起来像什么」
- 组件决定「能做什么」

**示例**：
- 一个箱子贴图 + 物理组件 → 能移动的箱子
- 一个箱子贴图 + 可互动物体组件 → 能被点击的箱子
- 一个箱子贴图 + 物理组件 + 可互动物体组件 → 能移动且能被点击的箱子

### 4.2 组件的六种分类

| 分类 | 组件示例 | 主要功能 |
|------|----------|----------|
| 通用 | 物理、阻挡通行、物体UI | 基础交互能力 |
| 战斗 | 生命、伤害、武器槽、子弹 | 战斗相关能力 |
| 装置 | 机关、机关门、机关地板 | 机关设计 |
| 显示 | 粒子特效、动效 | 视觉效果 |
| 交互 | 移动摇杆、技能摇杆、互动按钮 | 用户输入 |
| 自定义 | 自定义组件 | 自定义功能 |

### 4.3 给物体添加组件

1. 在地图中选中物体
2. 打开属性面板
3. 找到「添加组件」选项
4. 选择需要的组件类型
5. 配置组件参数

## 5. 脚本基础

### 5.1 什么是脚本

脚本是用积木块拼装的行为逻辑，决定对象在特定时机下「做什么」。

**基本结构**：
```
触发时机 + 积木块组合 = 脚本
```

### 5.2 脚本编辑器

脚本编辑器通常包含：
- **触发时机区**：选择脚本在什么时机执行
- **积木块区**：拖拽积木块组合成逻辑
- **操作区**：保存、试玩等操作

### 5.3 常见触发时机

| 触发时机 | 触发条件 |
|----------|----------|
| 当被创建时 | 对象创建时执行一次 |
| 当被点击时 | 对象被点击时执行 |
| 当接近时 | 玩家接近对象时执行 |
| 当收到广播时 | 收到指定广播时执行 |
| 当受到伤害时 | 对象受到伤害时执行 |

### 5.4 脚本的基本工作流程

1. **编辑脚本**：在脚本编辑器中编写逻辑
2. **保存**：保存脚本修改
3. **试玩**：运行游戏测试效果
4. **调整**：根据测试结果修改脚本

## 6. 试玩与保存

### 6.1 保存的重要性

> **关键**：在创游世界，保存脚本后才能生效。

如果不保存就试玩，可能看到的是旧版本的行为。

### 6.2 试玩操作

| 操作 | 说明 |
|------|------|
| 普通试玩 | 在编辑器内预览游戏 |
| 全屏试玩 | 全屏运行游戏 |
| 停止试玩 | 停止当前试玩，返回编辑器 |

### 6.3 调试技巧

- 使用「查看碰撞盒」检查阻挡区域
- 使用显示文字或广播输出变量值
- 使用逐行 Debug 查看执行流程

---

## 7. 快速问题解决

| 问题 | 解决方法 |
|------|----------|
| 角色走不动 | 检查是否挂了「角色组件」+「物理组件」 |
| 物体没有功能 | 检查是否添加了需要的组件 |
| 修改没生效 | 检查是否保存了脚本 |
| 找不到做好的 UI | 确认 UI 类型（地图UI/操作UI/物体UI），使用正确的切换指令 |
| 素材改了地图没变 | 使用「应用到原素材」或重新摆物体 |

# 创游世界发布与分享指南

[[toc]]

## 一句话摘要

本文介绍创游世界游戏的完整发布流程，包括发布前检查清单、平台配置、发布步骤和分享推广方法，帮助开发者顺利将游戏发布到平台。

## 核心结论

1. **发布前必须全面测试**：不要带着 Bug 上线，提前发现问题更容易修复
2. **遵守平台审核规则**：违规内容会导致审核不通过甚至封号
3. **准备好推广素材**：截图、视频、简介是吸引玩家的关键
4. **持续更新维护**：发布只是开始，后续更新和玩家反馈同样重要

## 发布前检查清单

### 功能完整性检查

| 检查项 | 说明 | 状态 |
|--------|------|------|
| 核心玩法 | 游戏主要玩法是否完整可用 | ☐ |
| 新手引导 | 新玩家能否顺利开始游戏 | ☐ |
| UI 界面 | 所有界面是否正常显示 | ☐ |
| 存档功能 | 保存和读取是否正常工作 | ☐ |
| 联机功能 | 联机模式是否正常（如有） | ☐ |

### 性能检查

| 检查项 | 说明 | 状态 |
|--------|------|------|
| 帧率稳定 | 游戏运行帧率是否稳定 | ☐ |
| 无崩溃 | 长时间运行是否会出现崩溃 | ☐ |
| 加载速度 | 启动和切换是否流畅 | ☐ |
| 内存占用 | 是否存在内存泄漏 | ☐ |

### 内容检查

| 检查项 | 说明 | 状态 |
|--------|------|------|
| 无违规内容 | 是否包含平台禁止的内容 | ☐ |
| 版权合规 | 使用的素材是否合规 | ☐ |
| 文字正确 | 是否有错别字或乱码 | ☐ |
| 音效正常 | 音效和音乐是否正常播放 | ☐ |

### 适配检查

| 检查项 | 说明 | 状态 |
|--------|------|------|
| 横竖屏适配 | 屏幕方向是否正确 | ☐ |
| 分辨率适配 | 不同分辨率是否正常显示 | ☐ |
| 全面屏适配 | 异形屏是否正常 | ☐ |
| 操作适配 | 触屏/键盘操作是否正常 | ☐ |

## 发布流程

### 步骤一：登录创游世界开发者平台

1. 打开创游世界官网
2. 登录开发者账号
3. 进入开发者后台

### 步骤二：创建新项目

1. 点击「创建游戏」或「发布新作品」
2. 填写游戏基本信息：
   - 游戏名称
   - 游戏简介
   - 游戏分类
   - 适用年龄

### 步骤三：上传游戏包

1. 导出游戏项目为可发布格式
2. 上传游戏包文件
3. 等待上传完成

### 步骤四：配置游戏信息

1. **游戏图标**：上传游戏图标（建议尺寸 512x512）
2. **游戏截图**：上传 4-8 张游戏截图
3. **游戏视频**：上传游戏宣传视频（可选）
4. **游戏简介**：编写吸引人的游戏介绍

### 步骤五：设置游戏参数

1. **游戏模式**：单机/联机
2. **游戏人数**：单人或多人
3. **游戏标签**：选择合适的标签
4. **氪金设置**：是否有内购

### 步骤六：提交审核

1. 检查所有信息是否正确
2. 点击「提交审核」
3. 等待平台审核

### 步骤七：审核反馈

- **通过**：游戏正式上线
- **不通过**：查看原因，修改后重新提交

## 平台审核规则

### 禁止内容

| 类型 | 示例 |
|------|------|
| 暴力血腥 | 过度血腥的画面、暴力鼓励 |
| 色情低俗 | 色情内容、低俗笑话 |
| 政治敏感 | 政治宣传、敏感话题 |
| 违法犯罪 | 赌博内容、诈骗教程 |
| 侵权内容 | 盗版素材、抄袭作品 |
| 虚假信息 | 谣言传播、欺诈内容 |

### 审核标准

1. **玩法完整性**：游戏必须有可玩的内容，不能是半成品
2. **体验流畅性**：游戏运行应该流畅，不能有明显卡顿
3. **内容原创性**：鼓励原创，不接受明显抄袭
4. **适宜年龄**：内容应适合所选年龄段

## 游戏截图和视频制作

### 截图技巧

1. **选择最佳画面**：截取游戏最美或最有趣的画面
2. **展示核心玩法**：截图应展示游戏的主要玩法
3. **注意画面质量**：确保截图清晰，不模糊
4. **统一风格**：所有截图风格应统一

### 视频制作

**推荐内容**：
- 游戏开场动画
- 核心玩法演示
- 特色系统介绍
- 玩家评论配音

**视频时长**：
- 宣传视频：30秒-1分钟
- 详细解说：2-5分钟

## 游戏简介编写

### 简介结构

```
【游戏名称】
【一句话介绍】
【详细说明】
【游戏特色】
【适合人群】
```

### 编写技巧

1. **开头要吸引**：第一句话就要抓住玩家
2. **突出特色**：说明游戏的独特之处
3. **语言简洁**：避免冗长，用词精准
4. **真实描述**：不要过度夸大，避免夸大其词

### 示例

> **冒险大陆**
> 一款融合 RPG 与策略的像素冒险游戏
> 
> 在这里，你将扮演一名勇敢的冒险者，探索神秘的大陆，收集稀有道具，挑战强大BOSS。
> 
> **游戏特色**
> - 自由探索：开放式地图，无限可能
> - 丰富系统：战斗、背包、任务多重玩法
> - 精美画面：复古像素风格，精美细腻
> 
> 适合喜欢冒险和探索的玩家！

## 常见问题

### Q1：审核需要多长时间？

**A**：通常需要 1-7 个工作日，具体时间视平台情况而定。

### Q2：审核被拒绝怎么办？

**A**：
1. 查看拒绝原因
2. 根据原因修改内容
3. 修改后重新提交
4. 如有疑问可联系平台客服

### Q3：游戏发布后可以修改吗？

**A**：可以修改游戏内容，但需要重新提交审核。频繁修改可能影响游戏排名。

### Q4：如何提高游戏曝光度？

**A**：
1. 优化游戏图标和截图
2. 编写吸引人的简介
3. 积极推广宣传
4. 持续更新维护
5. 鼓励玩家评分和评论

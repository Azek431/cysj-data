# 创游世界新手常见问题速查

[[toc]]

## 一句话摘要

创游世界新手常见问题的快问快答，帮助你快速解决角色不动、UI找不到、广播没效果、变量丢失等高频卡点。

## 适合谁阅读

- 遇到具体问题时需要快速查找答案的新手
- 想快速了解常见问题的创作者
- 需要快速定位问题的开发者

## 你将学到什么

- 基础概念：素材、物体、组件的区别
- 编辑器操作：UI切换、玩家添加
- 脚本逻辑：变量作用域、广播机制
- 数据管理：变量存储位置选择
- 版本兼容：旧教程的注意事项

## 核心结论

1. **素材≠物体**：素材是模板，物体是实例，修改素材不会自动更新地图物体
2. **组件=能力**：贴图决定外观，组件决定功能，不挂组件的物体只是静态图片
3. **变量有层级**：局部变量用完就消失，持久数据要放自身属性/地图属性/玩家变量
4. **广播是通知**：广播让不同对象之间发消息，不需要知道对方在哪

## 基础问题

### Q：素材和地图里的物体有什么区别？

**A**：素材是模板，放到地图里才变成物体。修改素材后，地图里的物体不一定自动更新。

### Q：组件到底是什么？

**A**：组件决定物体「能做什么」。贴图决定看起来，组件决定功能。不挂组件的物体只是静态图片。

### Q：为什么角色在地图里走不动？

**A**：检查是否挂了「物理组件」+「角色组件」。

### Q：广播是什么？

**A**：广播是一种「发消息给多个对象」的事件通知机制，让不同对象之间不需要知道对方在哪也能通信。

## 编辑器问题

### Q：为什么切换UI时找不到做好的UI？

**A**：创游有三种UI，每种UI的切换入口不同。地图UI→地图UI设置，操作UI→操作UI设置，物体UI→需要先挂「物体UI」组件。

### Q：为什么有两个UI重叠关不掉？

**A**：默认操作UI仍在自动生效。进入「操作UI设置」→找到「默认操作UI」→关闭或改空。

### Q：为什么互动按钮不显示？

**A**：互动按钮默认隐藏，只有玩家接近「可互动物体」时才显示。常驻按钮要用普通「按钮」组件。

### Q：怎么给地图重新添加玩家角色？

**A**：切换素材到「角色」分类→点击右下角「添加玩家」。

## 脚本问题

### Q：为什么脚本里的值会丢失？

**A**：检查变量是否放在了正确的位置。局部变量执行完就消失，需要持久化的值要放自身属性/地图属性/玩家变量。

### Q：为什么广播发出去没有效果？

**A**：检查：1)广播名称是否完全一致 2)监听脚本是否写在「当收到广播时」触发时机下 3)监听者是否还存在。

### Q：循环为什么会卡死游戏？

**A**：无限循环没有等待语句。UI动画更推荐用「渐变」语句，而不是无限循环。

### Q：为什么数值比较不生效？

**A**：检查两边是否是同一数据类型（数字vs文本形式的数字），浮点数比较建议用「是否约等于」。

## 数据问题

### Q：变量应该放哪？

**A**：看需要的作用范围。
- 临时计算→局部变量
- 单个物体状态→自身属性
- 同地图共享→地图属性
- 全局数据→系统属性

### Q：为什么UI状态切地图后错乱？

**A**：UI层临时状态不等于项目真值层。真值放地图层或系统层，UI只负责显示和接收输入。

### Q：表改了之后不生效？

**A**：修改配置表后，旧存档不会自动同步新结构。在「玩家开始时」脚本里做数据同步补丁。

---

## UI问题

### Q：联机时UI为什么会很卡？

**A**：4.52.54之前版本，每个玩家设备会模拟所有玩家的UI逻辑，帧率被限制到20帧。更新到新版本或优化广播模式可解决。

### Q：「当前UI」访问方式有什么变化？

**A**：4.52.54+版本中，「玩家.当前UI」已弃用，改用更短的「当前UI」。地图脚本不直接操作当前UI，推荐用「玩家.向当前UI发广播」。

### Q：素材改了，地图里却没变化？

**A**：地图里的物体是实例，修改素材模板不会自动更新已摆放的物体。使用「应用到原素材」同步，或重新摆物体。

## 组件问题

### Q：战斗系统的基本关系链是什么？

**A**：角色拥有武器槽→武器槽装备武器→近战直接伤敌/远程通过子弹伤敌→目标通过生命组件接收伤害→命中/击杀/死亡通过事件回调处理。

### Q：背包容量最大是多少？

**A**：200格。

### Q：音效和BGM有什么区别？

**A**：音效≤10秒(4.54.0前)/30秒(4.54.0后)，可30个同时播放；BGM无限制，仅1个。

---

## 版本问题

### Q：旧视频教程还能用吗？

**A**：可能有UI调用方式过时、bug绕法不再需要等问题。重点关注「引擎更新知识索引」了解版本差异。

### Q：老游戏怎么使用新版本特性？

**A**：大多数新特性只对新创建游戏生效。联机UI兼容可在「游戏设置→UI兼容选项」中选择「运行在本地」切换到新逻辑。

## 快速问题表

| 问题 | 答案 |
|------|------|
| 角色走不动 | 检查「物理」+「角色」组件 |
| 改了素材没变化 | 使用「应用到原素材」或重摆 |
| 脚本不执行 | 检查触发时机、名称是否正确 |
| 广播没效果 | 检查名称、监听触发时机、对象存活 |
| UI找不到 | 确认是哪种UI，去对应设置找 |
| 变量值丢失 | 检查变量作用域是否正确 |
| 循环卡死 | 添加等待语句 |
| 背包满 | 最大200格 |

# 创游世界新手快速入门清单

[[toc]]

## 一句话摘要

本文为创游世界新手提供一份核心操作清单，涵盖素材、组件、脚本、广播、UI的基础操作要点，帮助快速建立编辑器使用能力。

## 适合谁阅读

- 刚下载创游世界不知道从哪开始的新手
- 想要快速查阅核心操作要点的创作者
- 需要一份操作清单来复习的开发者

## 你将学到什么

- 编辑器的基本操作流程
- 素材与物体的关系和处理方法
- 组件的添加和配置方法
- 脚本的编写基础
- 广播的使用方法
- UI的基本操作

---

## 快速入口

> ⭐ **记住这 3 条核心规则**：
> 1. 素材 ≠ 物体，改素材不会更新已有物体
> 2. 组件 = 能力，不挂组件 = 静态图片
> 3. 脚本 = 触发时机 + 积木块

---

## 1. 编辑器基础操作清单

### 1.1 界面认识

| 区域 | 作用 |
|------|------|
| 素材区 | 管理项目中的所有资源 |
| 编辑区 | 编辑地图场景的主要区域 |
| 属性面板 | 查看和编辑物体属性 |
| 组件面板 | 管理物体的组件 |
| 脚本编辑器 | 编写积木脚本 |

### 1.2 基础操作

| 操作 | 快捷方式 | 说明 |
|------|----------|------|
| 新建素材 | 点击 + | 创建新的资源模板 |
| 拖入地图 | 拖拽 | 从素材区拖入编辑区 |
| 选中物体 | 点击 | 在编辑区点击选中 |
| 复制物体 | Ctrl+C / Ctrl+V | 复制粘贴 |
| 删除物体 | Delete | 删除选中物体 |
| 撤销操作 | Ctrl+Z | 撤销上一步 |
| 保存工程 | Ctrl+S | 保存当前工程 |

## 2. 素材与物体操作清单

### 2.1 素材操作

| 操作 | 说明 |
|------|------|
| 创建素材 | 在素材区点击 + 创建 |
| 编辑素材 | 双击素材进入编辑模式 |
| 删除素材 | 右键选择删除 |
| 导入素材 | 从外部导入图片资源 |
| 整理素材 | 使用文件夹分类管理 |

### 2.2 物体操作

| 操作 | 说明 |
|------|------|
| 放置物体 | 从素材区拖入编辑区 |
| 移动物体 | 拖拽或使用方向键 |
| 缩放物体 | 使用缩放手柄或属性面板 |
| 旋转物体 | 使用旋转手柄或属性面板 |
| 调整层级 | 在图层面板调整遮挡关系 |

### 2.3 关键规则

> ⚠️ **重要**：
> - 修改素材后，地图中已有的物体 **不会** 自动更新
> - 如需更新已放置的物体，使用「应用到原素材」或重新摆放

## 3. 组件操作清单

### 3.1 添加组件

| 步骤 | 操作 |
|------|------|
| 1 | 选中要添加组件的物体 |
| 2 | 打开组件面板 |
| 3 | 点击「添加组件」 |
| 4 | 选择需要的组件类型 |
| 5 | 配置组件参数 |

### 3.2 常用组件分类

| 分类 | 组件 | 用途 |
|------|------|------|
| 通用 | 物理组件 | 让物体具有物理属性 |
| 通用 | 可互动 | 让物体可被点击 |
| 通用 | 物体UI | 让物体显示UI元素 |
| 战斗 | 角色组件 | 让物体可被玩家控制 |
| 战斗 | 生命组件 | 管理生命值 |
| 战斗 | 伤害组件 | 造成伤害 |
| 战斗 | 武器槽 | 管理武器装备 |
| 战斗 | 子弹组件 | 发射子弹 |
| 装置 | 机关 | 设计机关逻辑 |
| 装置 | 机关门 | 可控制的门 |
| 装置 | 物体检测器 | 检测区域内的物体 |
| 显示 | 动效组件 | 播放动画 |
| 显示 | 粒子特效 | 播放粒子效果 |
| 交互 | 移动摇杆 | 虚拟摇杆控制 |
| 交互 | 技能摇杆 | 技能释放控制 |

### 3.3 组件注意事项

> ⚠️ **重要**：
> - 不挂组件 = 静态图片，物体不会有任何功能
> - 角色要能动：物理组件 + 角色组件
> - 物体要能交互：可互动组件

## 4. 脚本编写清单

### 4.1 脚本结构

```
触发时机（什么时候跑）
    ↓
积木块（做什么操作）
```

### 4.2 常用触发时机

| 触发时机 | 何时执行 |
|----------|----------|
| 当开始时 | 地图/物体创建时 |
| 当被创建时 | 对象被创建时 |
| 当被销毁时 | 对象被销毁时 |
| 当点击时 | 物体被点击时 |
| 当碰撞时 | 物体发生碰撞时 |
| 当接近时 | 玩家接近物体时 |
| 当受到伤害时 | 物体受伤时 |
| 当收到广播时 | 收到指定广播时 |

### 4.3 常用积木块

#### 控制类

| 积木块 | 功能 |
|--------|------|
| 如果...那么 | 条件判断 |
| 等待 | 暂停执行 |
| 停止当前脚本 | 停止脚本 |

#### 运算类

| 积木块 | 功能 |
|--------|------|
| 加、减、乘、除 | 数学运算 |
| 比较大小 | 数值比较 |
| 随机数 | 生成随机数 |

#### 数据类

| 积木块 | 功能 |
|--------|------|
| 新建变量 | 创建局部变量 |
| 设置变量 | 修改变量值 |
| 获取变量 | 读取变量值 |

#### 动作类

| 积木块 | 功能 |
|--------|------|
| 发送广播 | 发送广播消息 |
| 播放动效 | 播放动画 |
| 销毁自身 | 销毁当前物体 |

### 4.4 脚本常见错误

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 没有触发时机 | 脚本不执行 | 添加触发时机 |
| 无限循环无等待 | 游戏卡死 | 添加等待积木 |
| 广播名不一致 | 广播没效果 | 检查名称是否相同 |

## 5. 广播使用清单

### 5.1 发送广播

```
发送广播 "广播名称"
```

### 5.2 接收广播

```
当收到广播 "广播名称" 时
    执行相应逻辑
```


### 5.3 广播命名建议

| 推荐 | 不推荐 |
|------|--------|
| 打开界面 | 广播1 |
| 获得道具 | 调一下 |
| 敌人死亡 | 刷新 |

### 5.4 广播使用场景

| 场景 | 示例 |
|------|------|
| UI请求处理 | UI发广播 → 地图处理 → UI刷新 |
| 事件通知 | 敌人死亡 → 广播通知 → 任务检查 |
| 解耦通信 | A发广播 → B响应，无需直接调用 |

## 6. UI操作清单

### 6.1 三种UI类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 地图UI | 跟随地图 | HUD、提示框 |
| 操作UI | 覆盖界面 | 菜单、面板 |
| 物体UI | 跟随物体 | 头顶血条、对话框 |

### 6.2 UI基本操作

| 操作 | 说明 |
|------|------|
| 创建UI | 在UI编辑区创建 |
| 显示UI | 使用脚本切换显示 |
| 隐藏UI | 使用脚本切换隐藏 |
| 更新UI内容 | 设置UI元素属性 |

### 6.3 物体UI注意事项

> ⚠️ **重要**：
> - 物体UI需要先挂载「物体UI」组件
> - 不同UI类型使用不同的切换指令

## 7. 快速问题排查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 角色走不动 | 缺少组件 | 添加物理+角色组件 |
| 改了素材地图没变 | 素材≠物体 | 重新摆放或应用更新 |
| 脚本不执行 | 没有触发时机 | 添加触发时机 |
| 广播没效果 | 名称不一致 | 检查广播名称 |
| UI找不到 | UI类型错误 | 确认UI类型和指令 |
| 游戏卡死 | 无限循环 | 添加等待积木 |

# 创游世界编辑器界面详解

[[toc]]

## 一句话摘要

本文详细介绍创游世界编辑器各区域的功能、按钮和操作流程，帮助你深入理解编辑器的使用方法。

## 适合谁阅读

- 想深入了解编辑器各功能区的创作者
- 需要查找特定按钮功能的开发者
- 想系统学习编辑器操作的学习者

## 你将学到什么

- 编辑器各功能区域的作用
- 素材管理区的使用方法
- 地图编辑区的操作技巧
- 属性面板的配置方法
- 脚本编辑器的使用流程

## 核心结论

1. **编辑器分为素材区、地图区、属性面板三大区域**
2. **素材区管理所有资源，地图区编辑场景，属性面板配置物体**
3. **脚本编辑器是编辑行为逻辑的核心区域**
4. **试玩和保存是调试的基本流程**

## 1. 编辑器整体布局

### 1.1 主界面分区

```
┌─────────────────────────────────────────────┐
│  菜单栏（文件/编辑/视图/运行等）             │
├─────────────┬───────────────────────────────┤
│             │                               │
│   素材区    │         地图编辑区             │
│   （左侧）  │         （中央）               │
│             │                               │
│             │                               │
├─────────────┴───────────────────────────────┤
│              属性面板（右侧）                │
├─────────────────────────────────────────────┤
│              状态栏/预览区                   │
└─────────────────────────────────────────────┘
```

### 1.2 各区域简要说明

| 区域 | 主要功能 |
|------|----------|
| 菜单栏 | 文件操作、编辑操作、视图切换、运行控制 |
| 素材区 | 管理所有素材资源、组件配置、脚本模板 |
| 地图编辑区 | 编辑游戏场景、摆放物体、调整布局 |
| 属性面板 | 查看和修改选中物体的属性、组件、脚本 |
| 状态栏 | 显示当前状态、坐标、缩放等信息 |

## 2. 素材区详解

### 2.1 素材分类

| 分类 | 图标 | 用途 |
|------|------|------|
| 角色 | [角色图标] | 玩家角色、敌人、NPC等 |
| 装饰 | [装饰图标] | 场景装饰、背景元素 |
| 地块 | [地块图标] | 地形、地面、墙壁等 |
| 装置 | [装置图标] | 机关、门、开关等 |
| 道具 | [道具图标] | 可拾取物品 |
| 武器 | [武器图标] | 武器、装备 |

### 2.2 素材操作

| 操作 | 位置 | 说明 |
|------|------|------|
| 导入素材 | 素材区右键 | 从本地导入图片作为素材 |
| 新建素材 | 素材区右键 | 创建新的空白素材 |
| 复制素材 | 右键菜单 | 复制现有素材 |
| 重命名 | 右键菜单 | 给素材起名字 |
| 删除 | 右键菜单 | 删除不需要的素材 |
| 移动到文件夹 | 拖拽 | 在文件夹之间移动素材 |

### 2.3 文件夹管理

- **创建文件夹**：右键 → 新建文件夹
- **重命名**：双击文件夹名称
- **折叠/展开**：点击文件夹左侧箭头
- **删除**：右键 → 删除（会删除文件夹内所有内容）

## 3. 地图编辑区详解

### 3.1 工具栏

| 工具 | 图标 | 功能 |
|------|------|------|
| 选择 | [鼠标图标] | 选择地图中的物体 |
| 移动 | [十字图标] | 移动物体位置 |
| 缩放 | [缩放图标] | 缩放物体大小 |
| 旋转 | [旋转图标] | 旋转物体角度 |
| 撤销 | [撤销图标] | 撤销上一步操作 |
| 重做 | [重做图标] | 重做上一步操作 |

### 3.2 地图操作

| 操作 | 方法 |
|------|------|
| 移动视图 | 鼠标中键拖拽 / Ctrl+鼠标拖拽 |
| 缩放视图 | 鼠标滚轮 / Ctrl+滚轮 |
| 选择物体 | 左键点击 |
| 多选 | Ctrl+左键点击 / 框选 |
| 删除物体 | Delete键 / 右键菜单 |

### 3.3 放置物体

1. 在素材区选中素材
2. 拖拽到地图编辑区
3. 或双击素材直接添加到地图中心

### 3.4 调整物体

| 操作 | 方法 |
|------|------|
| 移动 | 拖拽物体 / 使用方向键 |
| 旋转 | 拖拽旋转手柄 / 右键菜单设置角度 |
| 缩放 | 拖拽缩放手柄 / 右键菜单设置大小 |
| 层级 | 右键菜单 → 置于顶层/底层 |

## 4. 属性面板详解

### 4.1 面板分区

| 分区 | 内容 |
|------|------|
| 基本信息 | 物体名称、坐标、旋转、缩放 |
| 组件 | 已挂载的组件列表 |
| 脚本 | 与物体关联的脚本 |
| 变换 | 位置、旋转、缩放的精确数值 |

### 4.2 组件管理

| 操作 | 方法 |
|------|------|
| 添加组件 | 点击「添加组件」→ 选择组件类型 |
| 移除组件 | 在组件列表中找到组件 → 点击删除 |
| 配置组件 | 点击组件 → 在下方查看/修改参数 |

### 4.3 脚本关联

| 操作 | 方法 |
|------|------|
| 打开脚本 | 点击「编辑脚本」→ 进入脚本编辑器 |
| 查看脚本 | 在脚本列表中查看已关联的脚本 |
| 移除脚本 | 在脚本列表中点击删除 |

## 5. 脚本编辑器详解

### 5.1 编辑器区域

```
┌─────────────────────────────────────────────┐
│  脚本编辑器                                  │
├─────────────────────────────────────────────┤
│  触发时机选择                                │
├─────────────────────────────────────────────┤
│                                             │
│           积木块编辑区                       │
│                                             │
│                                             │
├─────────────────────────────────────────────┤
│  [数据]  [保存]  [试玩]                     │
└─────────────────────────────────────────────┘
```

### 5.2 触发时机

| 触发时机 | 说明 |
|----------|------|
| 当被创建时 | 物体创建时执行一次 |
| 当被销毁时 | 物体销毁时执行一次 |
| 当被点击时 | 物体被点击时执行 |
| 当接近时 | 玩家接近物体时执行 |
| 当受到伤害时 | 物体受到伤害时执行 |
| 当死亡时 | 物体死亡时执行 |
| 当收到广播时 | 收到指定广播时执行 |
| 当执行指令时 | 自定义组件指令被调用时执行 |
| 重复执行直到 | 重复执行直到条件满足 |

### 5.3 积木块分类

| 分类 | 积木块示例 |
|------|------------|
| 控制类 | 如果...那么、重复执行、等待 |
| 运算类 | 加减乘除、比较、随机数 |
| 数据类 | 新建变量、设置变量、获取变量 |
| 对象类 | 获取对象、设置属性、销毁对象 |
| 动作类 | 发送广播、播放动画、移动到 |

### 5.4 底部功能

| 按钮 | 功能 |
|------|------|
| 数据 | 查看/编辑物体数据 |
| 保存 | 保存脚本修改 |
| 试玩 | 运行游戏测试 |

## 6. 试玩与调试

### 6.1 试玩模式

| 模式 | 说明 |
|------|------|
| 普通试玩 | 在编辑器窗口中预览 |
| 全屏试玩 | 全屏运行游戏 |
| 停止试玩 | 停止当前试玩，返回编辑器 |

### 6.2 调试功能

| 功能 | 说明 |
|------|------|
| 查看碰撞盒 | 显示物体的碰撞区域 |
| 打印日志 | 输出变量值或调试信息 |
| 逐行Debug | 单步执行脚本查看执行流程 |

### 6.3 常见问题检查

| 问题 | 检查项 |
|------|--------|
| 物体不动 | 是否挂了「物理」+「角色」组件 |
| 不能交互 | 是否挂了「可互动物体」组件 |
| 脚本不执行 | 是否在正确的触发时机下 |
| 修改没生效 | 是否保存了脚本 |

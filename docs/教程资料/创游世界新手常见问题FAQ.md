## 编辑器基础

### Q：创游世界在哪里下载？

**A：** 在手机应用商店搜索"创游世界"即可下载。编辑器是可视化拖拽式，不需要写代码。

### Q：创游世界需要编程基础吗？

**A：** 不需要。创游世界使用可视化积木块拼接逻辑，不需要写代码。但理解基本逻辑概念（如果...那么...、循环、变量）会有帮助。

### Q：编辑器里最基础的几个概念是什么？

**A：** 四个核心概念：
- **素材**：放到地图前的模板资源
- **物体**：素材在地图里的实例
- **组件**：赋予物体能力的模块
- **脚本**：用积木块拼装的行为逻辑

### Q：怎么给地图添加玩家角色？

**A：**
1. 切换素材到「角色」分类
2. 点击右下角「添加玩家」

## 素材与物体

### Q：素材和地图里的物体有什么区别？

**A：** 素材是「模板」，放在地图里才变成「物体」。

关键区别：
- 素材改了，地图里已有的物体不一定自动变
- 想批量改 → 修改素材
- 想单独改某个 → 直接在地图里改该物体

### Q：为什么改了素材，地图里的东西没变化？

**A：** 因为地图里的物体是实例，不是素材本身。

解决方法：
- 方案1：删掉旧物体，用新素材重新摆
- 方案2：选中地图物体 → 「应用到原素材」同步配置

### Q：怎么把物体复制一份？

**A：** 选中物体 → 长按 → 选择复制。或者在素材库复制素材，再拖入地图。

### Q：素材文件夹有什么用？

**A：** 用来整理素材，方便分类管理。右键素材 → 新建文件夹，可以把同类素材归在一起。

## 组件系统

### Q：组件是什么？

**A：** 组件是给物体赋予「能力」的模块。贴图决定「看起来像什么」，组件决定「能做什么」。

### Q：为什么我的角色走不动？

**A：** 可能的原因：
1. 缺少「角色组件」和「物理组件」
2. 地块自带「阻挡通行」
3. 碰撞盒设置过大

解决方法：给玩家对象添加「角色组件」和「物理组件」，检查地块阻挡设置。

### Q：官方素材为什么拿过来就能用？

**A：** 因为官方素材已经预先挂好了对应组件。自己做素材时，需要自己挂载组件才能赋予功能。

### Q：组件有哪些分类？

**A：** 六大分类：
- **通用**：物理、阻挡通行、物体UI
- **战斗**：生命、伤害、武器槽、子弹
- **装置**：机关、机关门、机关地板
- **显示**：粒子特效、动效
- **交互**：移动摇杆、技能摇杆、互动按钮
- **自定义**：自己写的组件

### Q：组件和脚本是什么关系？

**A：** 组件是「能力容器」，脚本是「调用这些能力的方式」。组件提供属性、指令和事件，脚本用积木块调用它们。

## 脚本系统

### Q：脚本是什么？

**A：** 脚本是用积木块拼装的行为逻辑，决定对象在「什么时机下」做「什么操作」。

基本结构：`触发时机 + 积木块组合 = 脚本`

### Q：脚本编辑器在哪里？

**A：** 选中某个物体 → 点击「写脚本」或「编辑脚本」→ 进入脚本编辑器界面。

### Q：什么是触发时机？

**A：** 触发时机决定脚本在「什么时候」执行。常见触发时机：
- 当被创建时
- 当被点击时
- 当收到广播时
- 当接近时
- 当受到伤害时

### Q：为什么我的脚本不执行？

**A：** 检查三点：
1. 是否设置了正确的触发时机
2. 是否有语法错误（条件写错、变量名写错）
3. 执行时机是否在监听者初始化之后

### Q：局部变量和系统属性有什么区别？

**A：**

| 类型 | 生命周期 | 存储位置 |
|------|---------|---------|
| 局部变量 | 当前脚本执行完就消失 | 脚本内部 |
| 系统属性 | 整个游戏期间 | 系统层 |

### Q：广播是什么？

**A：** 广播是一种「发消息给多个对象」的事件通知机制。发送者不需要知道谁在监听，监听者收到广播后自动执行对应逻辑。

### Q：为什么广播发出去没有效果？

**A：** 常见原因：
1. 广播名称写错了（注意大小写）
2. 监听脚本没有在「当收到广播时」触发时机下
3. 监听者在广播发送时已经被销毁

## UI 系统

### Q：创游有几种 UI？

**A：** 三种类型：
- **地图UI**：跟地图或场景级逻辑联动
- **操作UI**：玩家操作入口
- **物体UI**：绑定到特定物体

### Q：为什么切换 UI 时找不到做好的 UI？

**A：** 三种 UI 的切换入口不同：
- 地图 UI → 地图 UI 设置
- 操作 UI → 操作 UI 设置
- 物体 UI → 需要先给物体挂「物体 UI 组件」

### Q：为什么有两个 UI 重叠关不掉？

**A：** 默认操作 UI 仍在自动生效。解决方法：进入「操作 UI 设置」→ 关闭或改空「默认操作 UI」。

### Q：为什么互动按钮不显示？

**A：** 互动按钮默认隐藏，只有当玩家接近「可互动物体」时才显示。如果想做常驻按钮，使用普通「按钮」组件。

## 游戏系统

### Q：背包最大多少格？

**A：** 200 格。

### Q：音效和 BGM 有什么区别？

**A：**

| 类型 | 时长限制 | 同时播放数 |
|------|---------|----------|
| 音效 | 10秒内（4.54.0前）/ 30秒（4.54.0后） | 30个 |
| BGM | 无限制 | 1个 |

### Q：战斗系统的基本关系链是什么？

**A：**
```
角色拥有武器槽 → 武器槽装备武器 → 近战直接伤敌/远程通过子弹伤敌 → 目标通过生命组件接收伤害 → 命中/击杀/死亡通过事件回调处理后续
```

## 版本与兼容性

### Q：旧视频教程还能用吗？

**A：** 可能有以下问题：
- 旧的 UI 调用方式在新版本可能已弃用
- 旧的 bug 绕法在新版本可能不再需要
- 部分能力在新版本已有更优实现

### Q：「玩家.当前 UI」在新版本还能用吗？

**A：** 4.52.54+ 版本中「玩家.当前 UI」已弃用，改用更短的「当前 UI」。地图脚本将无法直接操作当前 UI，建议改用「玩家.向当前 UI 发广播」。

## 快速问题对照表

| 问题 | 快速答案 |
|------|---------|
| 角色走不动 | 检查是否挂了「角色组件」+「物理组件」 |
| 改了素材地图没变 | 使用「应用到原素材」或重新摆物体 |
| 脚本不执行 | 检查触发时机、名称是否正确 |
| 广播没效果 | 检查名称、监听触发时机、对象是否存活 |
| UI 找不到 | 确认是哪种 UI，去对应设置找 |
| 变量值丢失 | 检查变量作用域是否正确 |
| 循环卡死 | 添加等待语句 |
| 背包满 | 最大 200 格 |

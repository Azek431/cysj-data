# 关于

## 项目介绍

本项目（cysj-data）是创游世界引擎的非官方资料库与开发文档，由 Azek431 维护。目标是为创游世界用户提供全面的学习资源、系统解析和开发参考。

**适用人群：**
- 想系统学习创游世界的新手
- 需要深入研究脚本、组件、UI 的进阶开发者
- 想了解引擎版本演进的追踪者
- 需要查证据、做研究、整理知识的维护者

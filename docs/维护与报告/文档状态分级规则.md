# 文档状态分级规则

[[toc]]

## 1. 为什么需要状态分级

如果没有统一分级：
- 读者不知道一篇文档能不能直接信
- AI 不知道该把哪类文档当高权重入口
- 维护者也不知道应该先补哪一层

所以资料库里的文档，最好至少明确“成熟度”和“可信度”两件事。

## 推荐状态分级

### 1. 草稿
适用情况：
- 只有零散记录
- 结构不完整
- 标题与正文还没统一
- 基本没有回链或关联阅读

建议处理：
- 先补标题与摘要
- 再补最小结构
- 暂时不要当稳定入口页

### 2. 整理中
适用情况：
- 已有较明确主题
- 已开始分段与分类
- 但仍缺少证据、回链或统一头部

建议处理：
- 补一句话摘要
- 补适合对象 / 当前状态 / 可信度
- 补栏目入口与关联阅读

### 3. 已整理
适用情况：
- 结构完整
- 阅读路径清楚
- 已接入栏目页或总导航
- 有较明确的结论与说明

建议处理：
- 可作为稳定阅读入口
- 后续继续补 OCR 证据和双向链接

### 4. 核心入口
适用情况：
- 能承担栏目页或专题总入口作用
- 与多个高价值专题有稳定连接
- 对玩家和 AI 都有较高检索价值

建议处理：
- 保持结构稳定
- 每次扩写都要检查全局回链
- 尽量避免频繁大改路径或命名

## 可信度标记建议

除了状态，还建议统一写明可信度：
- `[已确认]`：有明确来源、已有较高把握
- `[高可信推断]`：虽未完全实锤，但已有较强上下文支持
- `[待验证]`：目前还不能直接下结论，需要继续查证

## 最小合格标准

一篇文档如果想达到“已整理”，建议至少满足：
- 有清晰标题
- 有一句话摘要
- 有适合对象
- 有当前状态
- 有可信度
- 有关联阅读
- 能从栏目页或总导航进入

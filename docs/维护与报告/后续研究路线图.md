# 后续研究路线图

[[toc]]

## 1. 概述

本路线图用于规划创游世界资料库的长期研究方向，帮助维护者有序推进知识库扩写工作。

### 路线图原则

1. **优先级驱动**：按 P0/P1/P2 分级，P0 优先完成
2. **证据密度**：优先探索直接证据丰富的领域
3. **闭环验证**：研究结论必须可验证、可追踪
4. **分阶段推进**：大目标拆成小阶段，逐步落地

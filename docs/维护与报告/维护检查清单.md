# 维护检查清单

一句话摘要：这是一份把维护动作落到执行层的检查表，用来帮助维护者在补文、修链、补证和收尾时不漏关键步骤。

- 适合对象：维护者、整理者、后续协作者
- 当前状态：已整理
- 可信度：`[已确认]`
- 关联文档：`docs/维护与报告/维护流程说明.md`、`docs/维护与报告/文档状态分级规则.md`、`docs/错误点与优化点汇总.md`

## 什么时候用这份清单

适合在下面几种场景使用：
- 新增栏目页之后
- 扩写专题正文之后
- 补 OCR 回链之后
- 批量修路径、命名或状态之后
- 准备结束一轮维护之前

## 一、入口检查

- [ ] 能否从 `docs/总索引与导航/创游世界知识库总导航.md` 找到
- [ ] 能否从所属栏目页找到
- [ ] 新增页面是否写入了关联阅读
- [ ] 相关栏目页是否同步接入新页面

## 二、结构检查

- [ ] 标题是否明确
- [ ] 是否有一句话摘要
- [ ] 是否标明适合对象
- [ ] 是否标明当前状态
- [ ] 是否标明可信度
- [ ] 是否说明这页适合解决什么问题

## 三、内容检查

- [ ] 是否区分“已确认 / 高可信推断 / 待验证”
- [ ] 是否存在明显过时的待办描述
- [ ] 是否说明推荐阅读顺序或使用顺序
- [ ] 是否补了常见误区 / 适用边界 / 当前判断

## 四、证据与回链检查

- [ ] 高价值专题是否补了 OCR 回链
- [ ] 是否能从专题反查到 OCR 文档或映射表
- [ ] 是否存在需要补“来源截图编号 / 对应 OCR 文档 / 对应映射表”的位置
- [ ] 是否把新证据同步到推进清单或状态总览

## 五、命名与一致性检查

- [ ] 路径名称是否统一
- [ ] 术语是否与术语表一致
- [ ] 状态词是否与统一状态词执行标准一致
- [ ] 同一类导航页的头部模板是否基本一致

## 六、收尾判断

满足下面大部分条件时，可认为这一轮维护基本完整：
- 页面已接入导航
- 页面结构完整
- 关键结论带有可信度说明
- 高价值文档已有最小回链
- 相关治理页已同步更新

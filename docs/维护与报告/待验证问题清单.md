# 待验证问题清单

[[toc]]

## 1. 使用说明

本文件用于追踪创游世界资料库中需要进一步验证、补充证据或持续追踪的问题。

### 可信度标签体系

| 标签 | 含义 | 使用场景 |
|------|------|----------|
| `[已确认]` | 多源证据充分，结论可靠 | 明确错误、已完成修复 |
| `[高可信推断]` | 单源强证据 + 逻辑自洽 | 推断结论、结构性缺陷 |
| `[待验证]` | 需要回测或补充证据 | 疑似错误、需要验证 |
| `[疑似错误]` | 发现异常但未定位根因 | 可疑点、待排查 |

> ⚠️ **重要提示**：所有研究型文档都应系统使用可信度标签，确保结论可审计。

## 核心概念速查

### 脚本、素材、组件、对象的关系

| 概念 | 说明 | 层级 |
|------|------|------|
| **素材** | 放在地图前的模板资源，包含贴图和可挂载的组件 | 模板层 |
| **物体** | 素材放到地图后的实例，有独立的状态和行为 | 实例层 |
| **组件** | 赋予物体能力的模块，决定物体能做什么 | 能力层 |
| **脚本** | 用积木块拼装的行为逻辑，决定物体何时执行什么操作 | 逻辑层 |

### 触发时机分类

| 触发时机 | 说明 | 常见用途 |
|----------|------|----------|
| 初始化 | 物体创建时执行一次 | 初始化变量、设置初始状态 |
| 每帧 | 每帧持续执行 | 移动、动画、检测 |
| 碰撞开始 | 两个物体接触时触发 | 伤害判定、拾取道具 |
| 碰撞结束 | 两个物体分离时触发 | 离开区域检测 |
| 收到广播 | 监听特定广播名称 | 事件驱动通信 |
| 手指按下/抬起 | 触屏交互 | UI 交互、按钮点击 |

## 常见问题速查

| 问题 | 答案 |
|------|------|
| 脚本不执行 | 检查触发时机是否正确，对象是否存在 |
| 广播没效果 | 检查广播名称是否完全一致，监听是否在正确的触发时机 |
| 变量值丢失 | 检查变量作用域，对象销毁后脚本变量会重置 |
| 循环卡死 | 使用「等待」积木或「每帧」触发时机 |
| 角色走不动 | 需要同时挂载「角色组件」和「物理组件」 |

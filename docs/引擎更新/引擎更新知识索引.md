## 1. 版本 4.54.0

### 新功能
1. 新数据类型：结构体
   - 允许将多个子属性打包成一个整体。
   - 更方便进行数据传递与数据存储。
   - 对 AI 理解而言，可视为一种复合数据结构。

2. 单选值类型优化
   - 原本单选值类型只能创建为自定义组件的属性。
   - 现在升级为公共类型。
   - 可在多处使用，例如：
     - 玩家变量
     - 配置表
     - 自定义指令的参数
     - 自定义指令的返回值

3. 向量属性新增能力
   - 新增“点乘”
   - 新增“叉乘”
   - 说明向量计算能力进一步增强，可支持更多空间计算或方向逻辑。

4. 数字属性新增能力
   - 新增“对数”
   - 新增“转换为文本”

### Bug 修复
1. 修复【从 a 到 b 内的随机数】脚本块问题
   - 当 a 比 b 大时，边界值随机不到。
   - 该问题已修复。

2. 修复音效会被【播放 BGM】打断的问题。

### 变动
1. 装置加【武器槽】组件后，执行朝向目标时：
   - 装置本身不应左右翻转。
   - 此修改带版本隔离。
   - 老游戏仍然会左右翻转。
   - 新创建的游戏不会翻转。

2. 上传音效时长限制提高到 30 秒。

3. 工程备份数量增加到 20。

## 2. 版本 4.52.60

### 新功能
1. 【预加载 BGM】优化
   - 预加载完成后，执行【播放 BGM】将立刻播放。
   - 没有延迟。

2. 【播放 BGM】高级参数增强
   - 增加淡入功能。
   - 增加变调功能。
   - 变调参数范围为 `-12` 到 `12`。

     - 设置当前播放时间
     - 暂停播放
     - 继续播放
     - 停止播放
     - 变调

1. 改造选择素材界面，支持文件夹显示。

2. 在属性面板或图层界面添加子物体时，弹出的选择素材界面新增“内置素材”页签。
   - 提供文字
   - 白色方块
   - 圆形
   - 空物体等基础对象
   - 方便快速使用
   - 避免在素材盒内重复创建素材

## 3. 版本 4.52.54

### 核心主题
- 联机 UI 优化
- UI 运行逻辑重构
- 联机环境下 UI 脚本同步机制调整

### 主要改动
1. 重构 UI 在联机环境下的运行逻辑。
   - 新版本中，每个玩家只运行自己的 UI 逻辑。
   - 老版本中，每个玩家设备会模拟所有玩家的 UI 逻辑。
   - 老方案为了保证同步，帧率被限制到 20 帧。
   - 新方案显著提升复杂 UI、多玩家 UI、UI 动画场景下的流畅度。

2. 更适合以下游戏场景：
   - 玩家人数较多。
   - UI 界面复杂，脚本较重。
   - 需要在 UI 中使用无限循环实现动画。
   - UI 频繁修改坐标、角度等显示属性。

### 脚本变动
1. 在联机环境下，UI 脚本操作地图或玩家公共数据时，会出现“上传并等待”流程。
   - 这是因为公共数据需要同步给其他玩家。
   - 每次同步大约需要 100ms。
   - 如果多条这类脚本串联，总耗时会明显增加。

2. 官方建议优化方式：
   - 不要在 UI 中连续做多次公共数据写入。
   - 更推荐只从 UI 向地图发送一次广播。
   - 地图收到广播后，在地图脚本中集中执行公共数据操作。
   - 这样可以减少上传次数，提高联机流畅度。

3. 【玩家.当前 UI】已弃用。
   - 自动替换为更短的【当前 UI】。
   - 在 UI 脚本里影响较小。
   - 但地图脚本将无法直接操作当前 UI。
   - 推荐替代方案：执行“玩家.向当前 UI 发广播”，由 UI 收到广播后再自行处理。

### 兼容与升级说明
1. 老版本单机游戏不受影响。
2. 老版本联机游戏可在“游戏设置 -> UI 兼容选项”中选择“运行在本地”，切换为新 UI 逻辑。
3. 切换后需要重新检查所有功能是否正常。
4. 此版本之后新创建的游戏默认使用新 UI 逻辑，无法回到旧逻辑。

## 14. 版本 4.33.86

### 粒子系统优化
1. 调整物体缩放对粒子发射区域大小的影响逻辑。
2. 新增“颜色过渡模式”选项，可选：
   - RGB：原模式。
   - HSB：新增模式。
3. 在 RGB 模式下，由白到黑渐变中间可能出现彩色。
4. 在 HSB 模式下，由白到黑渐变过程更偏灰阶，更符合预期。

### 联机优化
1. 为避免联机不同步，对【在某人视角下】执行的脚本增加限制。
2. 仅允许修改纯显示属性，例如：
   - 物体：颜色、透明度、混合模式、图片
   - 组件：公告板（文字/显隐）、拖尾（图片/颜色/时长）、描边（大小/颜色）、物体 UI
   - 地图：背景颜色、透明度

### 其他变动
1. 去除【系统.当前地图】，统一替换为【当前地图】。
2. 玩家变量数量提高到 200。
3. 云变量表最大行数提高到 1000。

### Bug 修复
1. 修复相遇模式中，其他玩家角色永远挡在最前面的 bug。
2. 修复对于非玩家角色，角色组件“跟随移动方向”选项不生效的 bug。

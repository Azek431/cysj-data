# OCR 图片编号映射表

## 1. 文档目的

本文用于建立“图片编号 → 主题 → 文档归属 → 状态”的统一映射，帮助知识库逐步从“高价值覆盖”推进到“逐图可追溯”。

它不是完整 OCR 原文，而是索引层。

---

## 2. 字段说明

每条映射建议至少包含：
- 图片编号
- 来源目录
- 主题归属
- 当前状态
- 对应 OCR 文档
- 对应专题文档
- 备注

状态建议使用：
- 已入档
- 已入档（待复核）
- 无有效文本
- 疑似重复页
- 待处理

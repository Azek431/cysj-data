- [已确认] 本表继续承担“图片编号 → 来源目录 → 主题归属 → OCR 文档 → 专题文档”的索引职责，不替代 OCR 原文。
- [已确认] 当前库中已显式写出的图片路径样本，均能在 `资料/` 目录下找到真实文件。
- [已确认] 当前更需要继续补的，不是旧路径修复，而是把更多已识别图片推进成逐号映射条目。
- [建议动作] 后续每补一张新图，优先同步 3 处：对应 OCR 文档、本映射表、推进清单。

## 0. 使用说明与可信度标签

为避免把推测写成事实，后续总报告、问题清单、研究专题统一优先使用以下可信度标签：
- `[已确认]`：有明确截图、OCR、官方教程或官方更新文字支持
- `[高可信推断]`：有多源交叉支撑，但缺少单条官方原文直接定性
- `[待验证]`：证据不足、OCR 残缺或仍需实测
- `[疑似错误]`：现有文档、编号、归属或旧结论可能有误，需优先核查

同时，映射表与 OCR 工程文档继续沿用统一状态词：
- 已入档
- 已入档（待复核）
- 无有效文本
- 疑似重复页
- 备份文件（`.hwbk`）
- 待处理

---


本文用于建立“图片编号 → 主题 → 文档归属 → 状态”的统一映射，帮助知识库逐步从“高价值覆盖”推进到“逐图可追溯”。

它不是完整 OCR 原文，而是索引层。

# OCR 当前状态与待补清单

这个页面用于回答一个最关键的问题：

> OCR 资料现在整理到什么程度了？还缺什么？应该先看哪一份？

由于 OCR 资料区包含原始识别、完整化表、证据链说明、未完成报告和阶段性补齐报告，新用户容易不知道从哪里开始。

所以本页面作为 OCR 区的当前状态入口。

| 类型 | 说明 | 推荐用途 |

## 当前待补方向

| 优先级 | 待补内容 | 说明 |
|---|---|---|
| P0 | OCR 缺失项复核 | 优先确认缺失内容是否仍然缺失 |
| P1 | OCR 残缺文本修正 | 对识别错误、断句错误、乱码内容进行人工修正 |
| P2 | 图片编号映射补全 | 保证 OCR 文本能回到对应截图或来源 |
| P3 | 专题文档回链 | 在脚本、UI、项目设计等专题中补 OCR 来源链接 |
| P4 | 证据等级标注 | 给重要 OCR 结论标记 E1/E2/E3/E4 |
| P5 | 历史报告归档 | 保留 V1/V2/V3，但明确当前入口和历史入口 |

## OCR 维护原则

1. 不轻易删除历史 OCR 报告。
2. 不把 OCR 识别内容直接当作最终结论。
3. OCR 原文、人工修正和研究结论应该区分。
4. 如果 OCR 文本无法确认，应标记为待验证。
5. 重要专题结论应尽量回链到 OCR 或截图来源。
6. 普通用户入口应尽量指向当前状态页，而不是多个历史报告。

## 后续建议

后续 OCR 区可以逐步整理成三层：

- OCR资料导航
- OCR 当前状态与待补清单
- OCR 原始资料 / 完整化表 / 证据链 / 历史报告

这样既保留历史维护记录，又能让普通用户更快找到当前最重要的信息。

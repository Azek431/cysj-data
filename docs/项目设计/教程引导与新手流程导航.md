## 新手引导设计要点

### 新手引导的核心原则

1. **循序渐进**：从简单到复杂，避免一次性灌输大量信息
2. **即时反馈**：每个操作都要有明确的反馈
3. **容错设计**：允许玩家犯错，并提供纠正机会
4. **成就感**：让玩家在学习过程中获得成就感

### 新手引导的典型步骤

```
第一步：角色移动
├── 教学点：虚拟摇杆使用
├── 目标：让玩家熟悉基本操作
└── 反馈：角色正常移动

第二步：交互操作
├── 教学点：与物体交互
├── 目标：理解交互机制
└── 反馈：打开对话框/触发事件

第三步：简单战斗
├── 教学点：攻击操作
├── 目标：理解战斗基础
└── 反馈：击败敌人

第四步：收集物品
├── 教学点：拾取物品
├── 目标：理解物品系统
└── 反馈：获得道具/货币

第五步：打开UI
├── 教学点：背包/商店
├── 目标：理解UI操作
└── 反馈：成功打开界面
```

## UI 提示设计

### 提示类型

| 类型 | 适用场景 | 设计要点 |
|------|----------|----------|
| 引导高亮 | 新手指引特定UI | 用高亮框或箭头指向目标 |
| 文字提示 | 说明操作方法 | 简洁明了，避免长段落 |
| 动画演示 | 复杂操作教学 | 直观展示操作流程 |
| 语音提示 | 需要注意力的情况 | 配合视觉提示使用 |

### 提示时机

| 时机 | 提示内容 |
|------|----------|
| 首次遇到 | 详细说明 + 演示 |
| 再次遇到 | 简化提示 |
| 多次重复 | 不再提示 |

## 教学关卡设计

### 教学关卡的设计原则

1. **隔离性**：新手教学关卡与正式游戏关卡分离
2. **目标明确**：每个教学点只有一个学习目标
3. **难度递进**：逐步增加操作复杂度
4. **即时奖励**：每次成功都有明确奖励

### 教学关卡的常见结构

```
开场介绍
├── 介绍游戏类型和核心玩法
└── 激发玩家兴趣

基础操作教学
├── 移动教学
├── 交互教学
└── 简单任务

进阶操作教学
├── 战斗教学
├── 物品使用教学
└── UI操作教学

综合练习
├── 多操作组合
├── 小型挑战
└── 给予成就感

正式进入游戏
├── 解除教学限制
└── 进入正常游戏流程
```

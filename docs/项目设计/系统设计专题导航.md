## 系统设计决策指南

### 选择系统类型的参考

| 游戏类型 | 重点系统 | 优先级 |
|----------|----------|--------|
| RPG | 战斗、背包、任务、商店 | 高 |
| 动作游戏 | 战斗、交互、物理 | 高 |
| 卡牌游戏 | 战斗、背包、商店 | 高 |
| 模拟经营 | 商店、存档、UI | 中 |
| 休闲游戏 | 交互、存档 | 中 |

### 系统依赖关系

```
物理系统（基础）
    ↓
交互系统（输入）
    ↓
战斗/背包/商店/任务（核心玩法）
    ↓
存档系统（持久化）
```
